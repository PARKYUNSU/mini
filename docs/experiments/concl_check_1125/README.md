## 2. 사전 등록 (11-25, 측정 전)

플래그 `RAG_CONCL_CHECK`(기본 0). 켜면:
- (a) 결론 다시 쓰기 v2 프롬프트에 "본론의 논문마다 한 번 이상 인용" 규칙.
- (b) 다시 쓴 결론이 본론 논문(관련 연구 표시가 아닌 것)을 빠뜨리면, 빠진 문서 번호를 알려 주고 한 번 더 부른다. 그래도 빠지면 더 많이 다룬 쪽을 쓴다(통과 검사는 그대로).
- (c) `A에서 B로 높/향상/증가` 인데 B<A(또는 낮/감소인데 B>A)면 그 결론은 탈락(원래 결론 유지).
- (d) 최종 답 결론의 결합 · 병행 효과 문장에 "(이 조합 자체는 논문에서 검증되지 않았습니다)" 를 붙인다.

측정: 오프라인 다시 돌리기. 저장된 trace 의 다시 쓰기 전 답 · 컨텍스트로 `rewrite_conclusion` 만 OFF/ON 각각 다시 부른다(같은 seed). 튜닝은 dev10(pa1_d)만, 판정은 held-out L30 · N30(pa1_l · pa1_n).

- 주 지표: held-out 에서 R2(관련 연구 아닌 논문 누락) 답 수 OFF → ON 이 절반 이하로 준다. R4 뒤집힘 0.
- 보호 1: 바뀐 결론 블라인드 쌍(Claude 판정)에서 나쁨 ≤ 좋음/2.
- 보호 2: 결론 길이 중앙값 증가 ≤ +40%, 다시 쓰기 시간 중앙값 증가 ≤ +5s.
- 보호 3: 문서 밖 숫자 · 본론 밖 인용 탈락이 OFF 보다 늘지 않는다(기존 검사 그대로).
