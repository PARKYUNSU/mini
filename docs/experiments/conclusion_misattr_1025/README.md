# 결론 논문 이름 오귀속 검사 — 개발 세트에서 중단 (2026-10-25)

> 사전 등록 **전** 개발 단계에서 멈췄다. 출발점: conclusion_v3_1024 · conclusion_overgen_1025 판정에서 결론 사실 오류 중 **한 논문의 이름 · 내용을 다른 논문 ID 에 붙이기**(DPS ↔ DynamicRAG, KG-LLM 을 엉뚱한 논문에)가 눈에 띄었다. 결론 다시 쓰기에는 숫자 검사만 있고 이름 검사는 없다.

## 1. 규칙 (`dev.py`)

- 결론 문장마다 인용한 논문 ID 의 블록을 모은다. 문장 앞에 붙은 인용(`[id] 다음 문장`)은 앞 문장 것으로 돌린다 — 단 `[id]은 / 는 / 이 …` 처럼 주어로 쓴 인용은 그대로 둔다.
- 문장의 고유 이름 토큰(라틴 문자 · 대문자 2개 이상 또는 숫자 섞임, 일반 약어 제외)이 그 블록들에 없고 **다른 논문의 제목**에 있으면 오귀속.
