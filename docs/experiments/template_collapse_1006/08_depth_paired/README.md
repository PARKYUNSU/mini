# 심층 모드는 작동하지 않는다 — 짝지은 측정 (2026-10-07)

운영 경로 36시행 (쌍 6개 × {일반, 심층} × 3회), 48분, 오류 0.
데이터 [`data.json`](data.json) · 스크립트 [`measure_depth.py`](measure_depth.py).

## 왜 다시 쟀나

[`../07_single_path/`](../07_single_path/) 에서 심층 효과를 **판정하지 못했다** — `wants_depth` 시행이 4개뿐이고 문서 수가 섞여 있었고, 무엇보다 `rag_context` **길이를 기록하지 않아** "지시가 들었나" 와 "컨텍스트가 늘어서 길어졌나" 를 분리할 수 없었다. 그때 "길이비 1.00배 → 효과 없음" 으로 적은 것은 **근거 없는 결론**이었고 철회했다.

## 설계

같은 질문의 `자세히` 유무 쌍 6개. 사전 검증으로 **두 변형이 모두 단일 경로**이고 **심층 플래그만 다름**을 확인했다 (`자세히` 를 붙이면 질의가 길어져 `len<=44` 조건을 벗어날 수 있다 — 6쌍 다 벗어나지 않는다). 측정 중에도 다시 확인했다: 심층 플래그 정확 ✓ · 전부 단일 경로 ✓.

컨텍스트 길이를 트레이스에서 뽑아 기록했다 — 07 의 구멍을 메운 것이다.

## 갈라서 읽는다

**검색 쪽 심층은 작동한다.** `_rag_context_same_paper_all_chunks` 가 컨텍스트를 1.8배로 늘린다 (527 → 952). 설계대로다.

**프롬프트 쪽 심층은 작동하지 않는다.** 재료가 두 배로 주어져도 모델은 600~700자, 본론 2항목을 쓴다. 쌍2 가 특히 분명하다 — 컨텍스트 **2.2배**에 답변은 **더 짧다**. 재료가 없어서가 아니라 **길이 지시를 듣지 않는 것**이다.

[`../05_conclusion.md`](../05_conclusion.md) 와 같은 성질이다: **v9 의 출력 길이·형태는 파인튜닝이 정하고 프롬프트 지시가 그것을 바꾸지 못한다.** 템플릿 탈취와 한 가족이다. 2026-10-07 에 다시 쓴 심층 지시도 같은 벽에 부딪혔다.

## 남은 판단

- **`wants_depth` 라우팅 유지**: 컨텍스트가 1.8배 늘어나는 것은 실재한다. 다만 **그 이득은 재지 않았다** — 길이만 쟀고 근거 충실도·정확성은 측정하지 않았다. "더 많은 근거로 답한다" 는 그럴듯하지만 측정된 주장이 아니다.
- **길이 지시**: 효과 0 으로 측정됐다. 죽은 프롬프트를 걷어내는 것이 이 라운드 전체의 방침이므로 제거가 일관되지만, 사용자가 명시적으로 "심층 기능을 되살린다"(2번)를 선택했으므로 임의로 되돌리지 않고 질의를 남긴다.

**길이를 늘리려면 프롬프트가 아닌 레버가 필요하다.** `num_predict` 는 4096 이라 상한이 아니다. 남는 것은 (a) 심층 질의만 다른 모델(base)로, (b) 항목별 분할 호출, (c) 길이가 긴 RAG 타깃으로 재학습 — 셋 다 이 라운드보다 큰 작업이다.
