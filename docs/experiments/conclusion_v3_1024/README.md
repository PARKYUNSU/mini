# 결론 v3 — 논문마다 한 문장, 여러 논문 묶기 금지 (사전 등록, 2026-10-24)

> 측정 **전에** 쓴다. 출발점: answer_judge_1024 기준선 — 결론 주장의 정확 51%(본론 84%), 사실 오류 16% · 과장 8%. 결론 사실 오류의 다수가 **한 논문의 주장을 두 논문의 공통 주장으로 묶기**(WAM 서베이 내용을 Graph World Models 와 함께 · WARD 의 한계 서술을 PI-Hunter 에도 · 두 논문 "공통 지적"), 과장은 "모든 연구가 … 공유" · "공통된 결론" 류. 운영 결론은 결론 다시 쓰기 v2(`RAG_CONCLUSION_PROMPT=v2`)가 만든다 — v2 지시("논문 간 결과가 같은지 갈리는지 짚고 판단")가 묶기를 부르는 것으로 본다.

## 1. 바꾸는 것 — `RAG_CONCLUSION_PROMPT=v3` (v2 와 같은 추출 · 같은 숫자 검사)

- **프롬프트 v3:** 질문 + 논문별 {제목 · 대상 · 결과}(v2 와 같은 `extract_findings`). 지시 — 논문마다 **정확히 한 문장**(그 논문의 결과 · 대상, 그 논문 **하나만** 인용), 마지막에 **한 문장**으로 논문들이 무엇이 다른지(새 사실 · 수치 없이, 인용 없이). "모든 연구 · 공통 · 모두" 같은 일반화 금지, 한 문장에 두 논문 이상 인용 금지.
- **검사 추가(v3 만):** ① 한 문장이 서로 다른 `[문서 N]` 둘 이상을 인용하면 탈락("여러 논문 묶음") ② "모든 연구 · 모든 논문 · 공통(된|으로|점) · 모두 … (공유|같)" 표현이 있으면 탈락("과잉 일반화"). 탈락하면 v2 와 같이 **원래 결론**을 둔다.
- 코드 `core/llm/conclusion_rewrite.py`, 테스트 `tests/unit/test_conclusion_rewrite.py`.

## 2. 방법 — 오프라인 (저장된 답에 결론 다시 쓰기만, 맥미니)

- 답: `pb1_real40` · `pb1_real2`(10-22 운영 설정 답, `numbered_context` 저장) 중 결론 다시 쓰기 대상(본론이 서로 다른 논문 2편 이상 인용)인 답 전부.

- **눈가림 판정:** 답마다 두 결론(v2 · v3, 바뀌지 않았으면 원래 결론)을 무작위 순서로 A · B 로 섞어, Claude 가 조건을 모른 채 그 답의 인용 블록과 대조해 문장마다 answer_judge_1024 의 라벨(정확 O · 사실 오류 E · 과장/일반화 X · 근거 없음 U · 군더더기 F · 확인 불가 ?)을 매긴다. 판정 뒤 공개.
