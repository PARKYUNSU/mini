## 고친 안 (덮어씌워 잼, 코드 변경 없음)

1. **주제 판정(1b)**: `_names_paper_topic` 에서 두 가지를 바꾼다.
   - 조사는 단어 끝에서만 지운다: `(에서|에|의|은|는|이|가|을|를|들)(?=\s|$|[?.!])`.
   - 채움말에 "저장되어 · 몇 개/편 · 개수 · 하나"를 더하고, 남은 글자 하한을 12 → 5 로 낮춘다.
   - 1a 도 재 봤다. "논문"을 뺀 글을 학술 LLM 판정(`is_academic_query_full`)에 다시 묻는 안이다. 이 안은 dev 7 은 고쳤지만 새 표현 "음성 인식 논문 중 재밌는 거 알려줘" · "논문 아무거나 재밌는거 하나 알려줘"를 못 잡아 버렸다.
2. **날씨(2)**: 질문에 "논문 · 연구"가 있으면 날씨 도구로 보내지 않는다.
3. **웹 검색(3)**: `get_search_intent` 의 RAG 막는 단어에 "연구"를 더한다.

- "2단계 → 바로 RAG" 문항은 원래도 3단계 LLM 분류를 거쳐 대부분 RAG 로 갔다(R8 1단계 116/120). 이제 3단계 분류 호출(RAG 검색 + LLM)을 건너뛰어 빨라진다.
- 3 으로 2단계까지 가게 된 두 문항(웹 검색 방법 연구 · Q_B04)은 라우터 전체를 두 번씩 돌렸다. 둘 다 RAG(B)로 갔다. 고치기 전에는 둘 다 웹 검색이었다.
- 남는 것: "사용자 질문을 검색하기 좋게 다시 써 주는 방법 알려줘"는 학술 판정이 아니라서(논문 · 연구 없음) 웹 검색 그대로다.
