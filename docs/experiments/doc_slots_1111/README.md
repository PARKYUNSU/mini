## 1. 바꾸는 것 — `RAG_DOC_SLOTS=1` (기본 0, 4f7c758)

- 일반 답 틀은 예시 칸이 3개이고 "2~4개" 규칙인데, v13 은 거의 늘 2개만 채운다. 목록 모드에서는 문서마다 번호 칸을 주자 인용이 31 → 59 로 늘었다(`list_slots_1016`).
- 같은 번호 칸 틀을 일반 질문에도 쓴다. 조건: 거르기 뒤 문서 3편 이상 · 목록 모드 아님 · 판정 '없음' 아님 · 항목별 판정 아님.
- 칸은 5개까지, 칸마다 1~2문장이다(컨텍스트가 목록 모드처럼 짧지 않아 n_ctx 4096 안에 넣으려는 것). 관련 없는 문서의 칸은 빼라고 지시한다.
- 검색 · 거르기 · 판정 호출은 그대로다. 판정 뒤에 답 호출의 틀만 바꾼다(단위 테스트 `tests/unit/test_doc_slots.py`).
- 질문 유형을 추측하지 않는다. `survey_gate_1030` 은 질문 문구 정규식으로 목록 모드를 켰는데, 실사용 10개 중 2개만 걸렸다.
