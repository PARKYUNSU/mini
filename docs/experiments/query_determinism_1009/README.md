# 검색어 추출을 결정적으로 (사전 등록)

- 시작일: 2026-10-09
- 선행: [`../route_fix_1009/README.md`](../route_fix_1009/README.md) §6.1 — RAG 경로 146문항에서 같은 코드인데 검색어만 달라 적중이 바뀐 문항이 한쪽으로만 7개.

## 1. 조치

`get_rag_query_rewrite_llm` (검색어 추출 `_extract_english_rag_query` 와 후속 질의 재작성 `_rewrite_rag_query` 가 함께 씀): temperature 0.2 → **0.0**, **seed=0**. 측정 전 확인: 같은 질문 4회 호출 → 4회 동일.

## 2. 측정

`eval_e2e_ko.py --label det_r1` · `--label det_r2` (162문항, 논문 모드 OFF, 답변 스텁).

## 3. 판정 (결과 전 고정)

- **결정성**: RAG 경로 문항 중 두 실행의 검색어가 같은 비율 ≥ **0.95**, 적중이 바뀐 문항 ≤ **2**.
- **정확도**: `det_r1` vs `rf_r1` 짝지은 비교에서 결정적 쪽이 유의하게 나쁘지 않다 (옛 쪽 우세 p<0.05 가 아님).
- 둘 다 통과하면 반영. 이후 끝단 비교는 단일 실행으로 해석할 수 있다.

## 4. 예상

결정성은 통과한다. 정확도는 rf_r1(0.784) 근처 ±0.04 — 그리디 디코딩이 평균적으로 더 낫거나 나쁠 이유는 없다.

## 5. 결과 (2026-10-09)

- **결정성**: 두 실행 모두 RAG 로 간 146문항에서 검색어 **146/146 동일**, 적중이 바뀐 문항 **0**, 경로가 바뀐 문항 0 → 통과. (라우터 3단계 분류 LLM 도 이번 162문항에서는 두 실행이 같았다.)
- **정확도**: `det_r1` 0.778 (= `det_r2`) vs `rf_r1` 0.784 — 짝지은 **5 : 6** (p=1.0) → 나빠지지 않음, 통과.
- **판정: 반영.** 이제 끝단 비교는 단일 실행으로 해석할 수 있다. 끝단 기준선은 **`det_r1` 0.778** 로 바꾼다 (A 0.746 · C1 0.917 · C2 0.800).
- 예상(결정성 통과, 정확도 ±0.04): 맞음.
