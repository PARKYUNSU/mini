- 시작일: 2026-10-09
- 선행: [`../e2e_ko_1008/README.md`](../e2e_ko_1008/README.md) §6~§8 — 논문 모드 OFF(운영 기본)에서 '논문'이 없는 논문 질문 139개가 RAG 에 0번 도달(끝단 0.074). ON 이면 0.716 이지만 잡담 9·계획 8개를 RAG 로 오염(9:0). 사전 규칙상 기본 ON 은 권고하지 않는다.

## 1. 조치

`is_rag_allowed(chat_id, q) = 논문 모드 or '논문' 단어` 에 **`or is_academic_query(q)`** 를 더한다. 라우터가 B(조회형)를 고른 뒤 RAG 로 갈지 Tavily/잡담으로 바뀔지를 정하는 자리다. 논문 모드 편향(`_apply_paper_mode_router_bias`)과 라우터 분류 자체는 건드리지 않는다.

분류기는 **결정적 어휘 규칙**으로 시작한다 — 지연 0, 재현 가능, 테스트 가능. 규칙으로 목표에 못 미치면 그때 LLM 판정을 검토한다.
