v6 의 `syntax` 24건이 **`timeout` 35건으로 바뀌었다.** 토큰을 5.1배 줘도 모델이 멈추지 않고, 이제 문항의 시간 제한(120초)에 부딪힌다. 잘림 신호는 16 → 2건으로 줄었다 — **토큰이 모자라서가 아니라 시간이 모자라서 끝난다.**

즉 근본 행동은 그대로다: **v6 는 종료하지 못한다.** 코딩 실패 42건 중 35건이 "120초 안에 못 끝냄" 이다 (base 6건). 상한을 바꾼 것은 실패의 라벨만 바꿨고, 그래서 기전이 오히려 선명해졌다.

(양쪽 모두 실패가 늘어난 것도 이 때문이다 — 800 에서는 일부 장황한 응답이 잘린 채로도 유효한 코드를 남겨 통과했는데, 4096 에서는 계속 쓰다가 시간 초과로 아무것도 남기지 못한다.)
