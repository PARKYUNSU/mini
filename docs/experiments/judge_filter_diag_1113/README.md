# judge_filter_diag_1113 — 거르기 · 판정 미달은 모델 탓인가, 과제 탓인가

model_cmp_1112 §3 · §5 에서 27b · 35b-a3b · 70b 가 거르기 · 판정 기준을 모두 못 넘었다. 재학습 · 큰 모델 전에, 이미 있는 재생 결과로 "모델끼리 일치" vs "모델 대 라벨 일치" 를 비교했다. 새 호출 없음 · 운영 영향 없음.

## 1. 거르기 (topic_filter_1104, 문서-행 580 = 상위 5 × 116 행)

| 쌍 | 남김/뺌 일치 |
|---|---|
| 27b-35b | 84.3% |
| v13-27b · v13-35b | 78.6% · 77.4% |
| 70b 와 나머지 | 73–74% |
| **각 모델 대 라벨** | **59.5–61.6%** |

- 네 모델이 다 남겼는데 라벨은 '주제 밖': 92/231. 네 모델이 다 뺐는데 라벨은 '주제 안': 17/104.
- 92 중 30 을 다시 봤다(모델 가림 없음 — 넷 다 같은 판단이라 가릴 것이 없음): **라벨이 맞음 19 · 경계 9 · 라벨이 틀림 2**.
- 틀리는 꼴은 둘이다.
  1. **낱말 맞추기**: 거르기 입력은 검색어 한 줄뿐이다(`r["line"]`, 예 `debate` · `contrastive search` · `nucleus sampling`). 질문 뜻이 빠져 있어 'AI 생성 토론 글' · '대조 학습 검색기' · 'RL 행동 샘플링' 을 남긴다.
  2. **넓은 서베이 · 일반 RAG 문서**를 하위 주제(예 계층 인덱싱 · corrective RAG)에 맞는다고 남긴다.
- 결론: 라벨은 대체로 맞고, 모델은 크기와 상관없이 **같은 입력에서 같은 방식으로** 틀린다. 거르기 입력에 질문 · 하위 주제 정의가 없는 것이 원인 후보 1순위.

## 2. 판정 (open_judge_1103, 167 문항)

| | v13 | 27b | 35b | 70b |
|---|---|---|---|---|
| 운영 꼬리 '없음' | 33 | **104** | **97** | 36 |
| 열린 요청 꼬리(oj 새 꼬리) '없음' | 10 | 6 | 4 | 2 |
| 새 꼬리 라벨 F·T 맞춤 (26) | 22 | **25** | **25** | 23 |
| 새 꼬리 ? 7 중 '없음' | 3 | 2 | 0 | 0 |

- **운영 꼬리는 모델 사이에 51–84% 만 일치**한다. v13 이 문서를 골랐는데 27b 만 '없음' 이라 한 76 문항 중 15 를 봤더니 **15/15 가 관련 문서가 있는 질문**(예 "탈옥 공격 논문 세 편" 에 탈옥 논문 다섯)이다 → 운영 판정 프롬프트가 v13 에 맞춰져 있고 다른 모델에선 무너진다. 라벨이 v13 '없음' 33 에만 달려 있어 §3 의 "68 · 76 개" 는 라벨 밖이었다.
- **새 꼬리는 네 모델이 95–99% 일치**하고 27b · 35b 는 F·T 를 25/26 맞춘다. G2 미달은 전부 '?'(부분 일치 7) 에서 났다 — 큰 모델은 부분 일치에 문서를 내놓는다. '?' 는 정의상 애매하므로 이것을 오답으로 세는 기준 자체가 문제다.

## 3. 결론 → 재설계 방향

1. **거르기 입력 바꾸기**: 검색어 한 줄 대신 원 질문 + 하위 주제 정의(한 문장)를 넣는다. 출력은 남김/뺌 대신 `핵심 / 관련 / 무관` 3단계.
2. **판정 꼬리 바꾸기**: 운영 꼬리를 모델에 덜 민감한 새 꼬리 형식으로 바꾸고, 출력에 '부분' 을 둔다(`있음 / 부분 / 없음`). 부분이면 답에서 "정확히 맞는 연구는 없고 가까운 연구는 …" 으로 밝힌다(answer_gap_1104 의 '묻힘 · 침묵' 과 같은 문제).
3. 두 단계를 하나로: 문서마다 "질문 요소 중 무엇을 채우나" 를 적게 하고, 판정 '없음 · 부분' 은 그 표에서 규칙으로 계산(direction_1111 의 요소별 근거 표와 같은 형식).
4. 위 형식으로 9B · 27B · 35B 재생 → 그때 크기 차이가 나면 큰 모델, 아니면 9B 유지. **재학습은 그 다음**(라벨 1–2천 필요).

라벨 재검토는 판정자 Claude 1명. 거르기 30 · 판정 15 표본은 무작위(seed 7 · 3).
