## 1. 바꾸는 것 — `RAG_HISTORY_GATE` (기본 `0`)

`1` 이면 논문 질문(B 경로)에서 질문이 **이어지는 질문**일 때만 대화 기록을 쓴다:
- 판정 `is_followup(질문)`: 지시어·이어 묻기 표현("그 중", "그 논문", "이 연구", "위에서", "방금", "다른 논문도", "더 자세히", "두 번째", "N번", "이어서", "추가로" 등) 또는 아주 짧은 질문(공백 빼고 8자 이하). 애매하면 이어지는 질문으로 본다(그러면 지금과 같다).
- 이어지는 질문이 **아니면**: 검색어 추출 · 검색 재작성에 기록을 넣지 않고(라우터 · 답변 노드 둘 다), 답변 프롬프트의 `[대화 맥락]` 을 비우고 `[직전 답변]` 을 뺀다.
- 라우터 분류(A/B/C 고르기)는 그대로 기록을 본다. 잡담 · 계획 경로는 바꾸지 않는다.

## 2. 방법 — 다회차 평가 (맥미니)

- **대화 하나로 이어서 묻는다**(`eval_e2e_ko.py --keep-session`: 문항 사이 기록을 지우지 않음). 실제 사용과 같다.
- 순서: real40 40 + real2 34 = 독립 질문 74개를 고정 시드(1019)로 섞고, 그 사이 정해진 자리에 **이어지는 질문 10개**(F01–F10)를 끼운다 — `seq_questions.tsv` · `seq_gold.jsonl`(id 앞에 `r1_` · `r2_`).
- 대조 `mt0`(`RAG_HISTORY_GATE=0`, 지금 운영) · 처리 `mt1`(`=1`), 같은 순서, 운영 `.env` 그대로, `--answer --save-context`. 인용 교정 통계(컨텍스트에 없는 ID 인용 수)를 행에 남긴다.
- 기준점: 같은 74문항을 기록 없이 잰 `s18_real40` · `s18_real2`(status_1018).

## 3. 판정 (측정 전 고정)

| 지표 | 기준 |
|---|---|
| **주:** 독립 74문항 중 **오염된 답** 수 — (a) 컨텍스트에 없는 논문 ID 를 인용(인용 교정이 지운 것 ≥ 1) 또는 (b) 직전 답과 글자 12-gram 겹침 ≥ 25% | 처리 < 대조, McNemar 양측 p < 0.05 |
| 보호: 독립 74 검색 ok · 수치 N 정답 · 비교 C 두 편 인용 · 목록 T 정답 인용 ≥ 3 | 각각 처리가 대조보다 2 이상 낮지 않음 |
| 보호: 이어지는 질문 10개 — 주제 유지(컨텍스트가 직전 컨텍스트와 논문 1편 이상 겹침) | 처리 ≥ 대조 − 2 |
| 보호: 응답 시간 중앙(74) | ≤ 대조 + 5s |
| 보고: 판정기가 이어지는 질문으로 본 수(74 중 · 10 중), 74문항의 검색 ok 를 기록 없는 `s18` 과 비교, 오염 (a) · (b) 따로 | |

주 지표의 대조 쪽 오염이 적어(예: 5건 미만) 검정력이 없으면 그대로 적고, 채택은 보호 기준 + 방향으로 사용자와 정한다.

채택이면 **사용자 승인 후** 운영 `.env` `RAG_HISTORY_GATE=1` + 봇 재시작.

예상: 대조 오염 8~15/74 → 처리 0~3. 검색 ok 는 처리가 s18 수준(대조보다 +2~5). 이어지는 질문은 판정기가 10/10 잡아 그대로.
