## 2. 문제없던 것

- 봇 접근 제어: 수신기의 모든 핸들러가 허용된 chat ID 만 받는다.
- git: 추적 파일과 이력 596커밋에 비밀 값 꼴 없음(텔레그램 · OpenAI · Groq · Google · GitHub · AWS · Notion · HF 꼴 검사). `.env` · `.bridge/` · `raw_data_queue/` · `.cron/` 은 무시된다. `.env.example` 은 자리표시뿐이다.
- Chroma · Ollama 는 `127.0.0.1` 에만 묶여 있다.
- 전원: 잠자기 꺼짐 · 정전 뒤 자동 재시작 켜짐. 수집 감시(03:30)가 수집 누락 · 스케줄러 죽음 · 디스크 10% 미만을 알린다.
