# 결론을 "상황 → 권고 + 근거 결과 [인용]" 으로 다시 쓰기 — 보조 호출 · 오프라인 평가 (사전 등록, 2026-10-21)

> 측정 **전에** 쓴다. 출발점: 실제 사용(10-21 16:20) "RAG 문서 청킹 전략(고정 길이, 의미 단위 등)을 비교한 연구 있어?" — 본론은 세 논문의 **방법**만 설명하고 결론은 "…어떻게 개선하는지를 보여줍니다" 같은 상투어였다. 사용자가 바란 결론: "범용 텍스트라면 오버랩 없는 문장 청킹이 가장 비용 효율적인 기본값이다(2601.14123). 문서 유형이 다양하면 메트릭 기반 적응형 선택이 정확도를 약 10%p 올린다(2603.25333). 표와 그림이 많은 PDF에는 멀티모달 청킹이 유망하지만, 근거는 아직 소규모 평가에 머문다(2506.16035)."

## 0. 진단

세 논문 초록(운영 컨텍스트, 초록 2,000자)에 바란 결론의 근거가 다 있다: 2601.14123 "overlap provides no measurable benefit … sentence chunking is the most cost-effective method", 2603.25333 "answers correctness to 72% (from 62-64%)", 2506.16035 "curated dataset … manually crafted queries … qualitative analysis". **검색이 아니라 결과를 뽑아 권고로 묶는 단계**가 비어 있다. 답변 프롬프트에 형식 지시를 더하는 것은 이 모델이 무시해 왔다(template_collapse_1006) → 답을 낸 뒤 **결론만 따로** 쓰게 한다.

## 1. 바꾸는 것 — `RAG_CONCLUSION_REWRITE` (기본 `0`)

`1` 이면 RAG 답 후처리 끝(인용 교정 · 항목 합치기 · 번호 매기기 뒤, 외부 검색 덧붙이기 앞)에서:
- **대상:** 본론 항목이 서로 다른 논문을 **2편 이상** 인용한 답.
- **호출:** 답변 모델(`RAG_ANSWER_MODEL`, temperature 0, seed 0, 비-thinking)에 질문 · 본론이 인용한 문서 블록(`[문서 N]` 라벨 그대로) · 답의 본론을 주고, 결론만 2~4문장으로 쓰게 한다 — 문장마다 "어떤 상황·조건이면 → 무엇이 낫다/어떻다 + 초록의 결과(수치는 문서에 적힌 그대로) + `[문서 N]`".
- **검사(통과 못 하면 원래 결론 유지):** 인용 1개 이상 · 길이 40~700자 · 새 결론의 숫자가 모두 **그 결론이 인용한 문서 블록 안에 그대로** 있음(계산한 값 금지) · 한자 없음.
- 통과하면 `[문서 N]` 을 기존 `fix_citations` 로 ID 로 펼쳐 결론 칸을 바꾼다.
- 코드: `core/llm/conclusion_rewrite.py`, 테스트 `tests/unit/test_conclusion_rewrite.py`.

## 2. 방법 — 오프라인 (맥미니, 저장된 답에 보조 호출만)

`s18_real40` · `s18_real2`(기록 없는 단일 질문, `--save-context` 로 `numbered_context` · `doc_ids` 저장됨) 중 대상 조건(본론 2편 이상)에 드는 답 전부에 보조 호출을 실제로 돌린다(운영 Ollama · v13). 답의 나머지는 그대로라 결론 차이만 본다. 스크립트 `docs/experiments/conclusion_rewrite_1021/offline.py`.

## 3. 판정 (측정 전 고정)

| 지표 | 기준 |
|---|---|
| **주:** 결론에 **근거 결과**가 있는 답 — 결론의 한 문장이 인용을 달고, 그 문장의 숫자가 인용한 문서 블록에 그대로 있음 | 후 > 전, McNemar 양측 p < 0.05 |
| 보호: 최종 결론에 인용 문서 밖 숫자가 있는 답 | 후 0 |
| 보호: 수치 N 정답 · 비교 C 두 편 인용 · 목록 T 정답 인용 ≥ 3 | 후 ≥ 전 |
| 보호: 보조 호출 시간 중앙 | ≤ 20s |
| 보호: 바뀐 결론 15개 직접 읽기(문서 초록과 대조) | 사실 왜곡(문서와 다른 주장 · 인용 논문이 그 주장을 안 함) ≤ 1 |
| 보고: 검사에 걸려 원래 결론을 둔 비율과 사유, 유형별(N · C · T · R) 바뀐 수, "조건 → 권고" 꼴 문장 수(직접 읽기) | |

채택이면 **사용자 승인 후** 운영 `.env` `RAG_CONCLUSION_REWRITE=1` + 봇 재시작. 응답 시간이 늘므로(+보조 호출) 실제 사용 응답 시간을 반영 뒤 확인한다.

예상: 근거 결과가 있는 결론 전 0~10% → 후 50~70%. 검사 탈락 20~40%(숫자 계산 · 인용 누락). "근거가 아직 소규모" 같은 비판적 판단은 드물 것.
