## 4. 판정 (결과 전 고정)

- (a) 목표 5문항 중 **4개 이상**이 `direct_answer/B` 로 간다. 끝단 `rf_r1` vs `single_off` 에서 새 쪽만 맞힌 수 ≥ 옛 쪽만 맞힌 수.
- (b) chat+planner 의 Tavily 경로 14 → **2 이하**, RAG(B) 경로 **2 이하** (논문 모드 오염 문턱과 같다).
- 이 표본으로는 (a) 의 효과가 최대 5문항이라 McNemar 유의(6:0)가 원리적으로 어렵다 — 그래서 "회귀 없음 + 목표 문항 이동" 으로 판정한다.
- 모두 통과하면 반영.

## 6. 결과 (2026-10-09)

**(a) 목록 도구**: 목표 5문항 **5/5** 가 `direct_answer/B` 로 이동, 그중 4개 적중 (`C2_13` 은 RAG 로 갔지만 검색 미스). 끝단 `rf_r1` vs `single_off`: **11 : 8** (p=0.65) — 새 쪽만 ≥ 옛 쪽만 → 통과.
잃은 8개 중 7개(`A049`·`A054`·`A061`·`A098`·`A108`·`A111`·`C2_11`)는 경로가 같고 **LLM 검색어 추출이 실행마다 다른 키워드를 낸** 것이다. `A037` 은 라우터 LLM 이 planner 로 보냈다. 수정과 무관한 흔들림이다.

**(b) 웹검색**: chat Tavily **7 → 0**, planner **7 → 0**, RAG(B) 0·0 → 통과. 빠진 14개는 모두 잡담(A)으로 갔다. 그 밖에 라우터 LLM 분류가 바뀐 문항 5개(`chat_11`·`chat_44`·`planner_35`·`planner_54`: A→C, `planner_57`: C→A).

**판정: 둘 다 통과 → 반영.** 끝단 0.765 → **0.784** (A 0.737 · C1 0.958 · C2 0.850).

### 6.1 새로 드러난 것 — 검색어 추출의 흔들림

RAG 경로가 146문항으로 늘자 흔들림이 커졌다. 같은 코드 경로에서 검색어만 달라 적중이 바뀐 문항이 한쪽으로만 7개다(e2e_ko_1008 §6 의 1.9% 는 RAG 경로가 18문항이던 때 값). 검색어 추출 LLM(`get_rag_query_rewrite_llm`, temperature 0.2)이 다음 개선 후보이자, **앞으로 끝단 비교에서 ±7문항 안팎의 차는 해석하지 않아야 하는 이유**다.
