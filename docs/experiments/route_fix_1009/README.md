## 2. 조치

- (a) `_names_paper_topic(q)` — '논문'을 빼고도 학술 주제가 남거나(게이트), 요청어·조사를 빼고 내용이 12자 이상이면 **주제 질문**으로 보고 목록 도구 대신 RAG. "최근 논문 알려줘"·"저장된 논문 뭐 있어?" 는 그대로 목록.
- (b) `is_factual_lookup` — 출력 형식 제약(`N줄`, `N자 이내`, `'…' 빼고/금지/쓰지 마`)이나 조언형 표지(요령·방법을·말투·계획·절차·차례·단계·"왜 ")가 있으면 사실 조회가 아니다.
- 양쪽 방향 회귀: [`tests/unit/test_route_fix_1009.py`](../../../tests/unit/test_route_fix_1009.py) (목록·뉴스·정의 질문은 그대로) + 기존 라우팅 golden 테스트 — 65 통과.

## 4. 판정 (결과 전 고정)

- (a) 목표 5문항 중 **4개 이상**이 `direct_answer/B` 로 간다. 끝단 `rf_r1` vs `single_off` 에서 새 쪽만 맞힌 수 ≥ 옛 쪽만 맞힌 수.
- (b) chat+planner 의 Tavily 경로 14 → **2 이하**, RAG(B) 경로 **2 이하** (논문 모드 오염 문턱과 같다).
- 이 표본으로는 (a) 의 효과가 최대 5문항이라 McNemar 유의(6:0)가 원리적으로 어렵다 — 그래서 "회귀 없음 + 목표 문항 이동" 으로 판정한다.
- 모두 통과하면 반영.
