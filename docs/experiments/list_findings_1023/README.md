## 0. 진단

## 1. 바꾸는 것 — `RAG_LIST_FINDINGS` (기본 `0`)

`1` 이면 `_compact_list_blocks` 가 블록마다 머리 + **같은 500자 예산**으로 초록에서 문장을 골라 원래 순서로 잇는다: ① 제안 문장(we propose / present / introduce … 이 든 첫 문장) ② 결과 문장(conclusion_rewrite_1021 §8 `extract_findings` 의 점수 — 수치가 든 결과 > 결과 동사) ③ 대상 문장(데이터셋 · 도메인). 예산을 넘는 문장은 뺀다. 초록이 없는 블록은 지금처럼 본문 앞 500자. 코드 `core/llm/conclusion_rewrite.py` `brief_findings`, `core/graph/agent_nodes.py`, 테스트.
