# term_fix_1118 — 알려진 잘못된 음차 · 본론 항목 제목 (사용자 3차 피드백 S7)

> 결정적 규칙(모델 호출 없음)이라 held-out 쌍 비교 대신 **저장된 답에 적용해 바뀐 줄을 전부 읽는다**. 플래그 `RAG_TERM_FIX`(기본 0), 형식 다듬기 · '없음' ID 정리 뒤에 적용.

## 1. 바꾸는 것 (`core/llm/format_fix.py`)
- 용어표(저장 답 2,551개에서 실제로 나온 것만): 차킹 · 채킹 · 청크링 → 청킹, 허할루시네이션 → 환각, 판판 → 판정자(받침 달라 이/은/을 → 가/는/를), `CoT-라울러/라테이션` → `CoT 근거 설명`. '체킹' 은 팩트 체킹과 겹쳐 넣지 않음. '할루시네이션' 은 쓰이는 외래어라 그대로.
- 본론 항목을 `제목: 요약` 꼴로: `(관련 연구)` 뒤 · `**이름**` 뒤 · 영어 이름 뒤 빠진 콜론을 넣고, 이름 자리에 `[ID]` 만 있거나 한글 문장으로 시작하면(W10 2번) 인용 논문 제목(콜론 앞 부분)을 붙인다. 문장 첫 영어 단어(`T5 기반 모델은`)는 그 논문 제목에 들어 있을 때만 이름으로 본다.
