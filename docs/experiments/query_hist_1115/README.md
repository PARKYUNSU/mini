# query_hist_1115 — 검색어 재작성에 직전 1턴만 (사전 등록, 2026-11-15)

> 측정 **전에** 쓴다. followup_v2_1115(held-out 미달 9:3 p 0.146)에서 효과가 거의 다 "검색어 기록 1턴" 에서 나왔다(새 논문 찾기 5:0). 그 하나만 새 held-out 으로 잰다. followup_v2 의 75 턴은 결과를 본 뒤라 쓰지 않는다.

## 1. 바꾸는 것 (`RAG_QUERY_HIST_TURNS`, 기본 2 = 지금)
- `1` 이면 논문 질문 검색어 재작성(`_extract_english_rag_query`)에 넣는 대화 기록을 직전 1턴만. 기록을 넣을지(대화 기록 게이트)는 그대로.
- 이어지는 질문의 직전 컨텍스트 재사용 · 판정 · 외부 검색 규칙은 바꾸지 않는다(외부 검색은 이 검색어를 쓰므로 영향을 받는다).
- 단위 테스트 `test_query_hist_turns`, 전체 799 통과.

## 2. 측정 (측정 전 고정)
- 세트: 이 폴더 `seq_questions.tsv` 80 턴 = `judge_v2_1113/heldout120.tsv` 의 **짝수 번째** 60 문항(followup_v2 가 쓰지 않은 쪽, 독립) + 3 문항마다 이어지는 질문 1 개(20 개: 새 논문 찾기 `QN01–12` · 직전 답 가리킴 `QH01–08`). 이어지는 질문은 답을 보기 전에 정했고 이전 세트들과 문장이 다르다. `QN` 은 모두 기록 게이트 통과 · 재사용 안 함, `QH` 는 모두 재사용(만든 스크립트가 확인).
- 한 대화(`--keep-session --answer --save-context`), 대조 `qh2`(`=2`) → 새 `qh1`(`=1`), 그 밖 운영 `.env` 그대로.
- **주 지표**: 이어지는 질문 20 개 중 두 답이 다른 문항을 무작위 순서 · 조건 가림으로 쌍 비교(판정자 Claude 1 명, 보는 것: 직전 질문 · 직전 답 · 지금 질문 · 두 답). 기준(followup_v2 와 같음): "직전 질문 · 답을 이어받아 지금 질문에 맞게 답한 쪽. 직전 답과 무관한 주제 · 논문으로 답하거나, 직전 답 논문이 있는데 '찾을 수 없다' 고 하면 진다. 문서와 맞지 않는 내용이 있으면 진다." **새 나음 > 나쁨, 부호 검정 p < 0.05.**
- **보호** (하나라도 넘으면 미달):
  - G1 독립 60 중 검색어가 바뀐 문항 쌍 비교(기준 "질문에 맞게 문서 근거로 답한 쪽"): 새 나쁨 ≤ 새 나음 + 1 (바뀐 문항만 — 바뀌지 않은 문항은 이 플래그가 닿지 않는다)
  - G2 독립 B 층(정답 논문 있음) 검색 ok: 새 ≥ 대조 − 1
  - G3 독립 60 문항 시간 중앙: 새 ≤ 대조 + 5s
- 보고만: `QN` · `QH` 별 승패, 이어지는 질문 검색어가 직전 질문 주제인지(직접 읽기), 외부 검색 붙은 수.
- 통과 → 운영 켜기 승인 요청(`RAG_QUERY_HIST_TURNS=1`). 미달 → 접고 플래그 코드 삭제.
