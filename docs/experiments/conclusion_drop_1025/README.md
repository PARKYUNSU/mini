# 결론 묶기 문장 지우기 — 다시 쓰기 탈락 시 후처리 (사전 등록, 2026-10-25)

> 측정 **전에** 쓴다. 출발점: conclusion_v3_1024 — 결론 다시 쓰기(v2 · v3)가 검사에서 떨어지면 **원래 결론**이 그대로 남고, 그 원래 결론에 묶기 · 일반화 오류가 그대로 있었다(Q14 · Q17 · Q18 · Q22 · Q38 · Q39 · Q40 · Q44, v2 · v3 둘 다 탈락). 새 프롬프트는 사실 오류를 늘렸으므로(3 → 9) 이번에는 **새 호출 없이 지우기만** 한다.

## 1. 바꾸는 것 — `RAG_CONCLUSION_DROP_BUNDLED=1` (기본 0)

- 결론 다시 쓰기(운영 v2)가 **바꾸지 못했을 때**(검사 탈락 · 호출 실패; "대상 아님"은 제외)만, 남은 원래 결론에서 문장을 지운다:
  1. 한 문장이 서로 다른 논문 둘 이상을 인용(`[2503.20320v1][2412.15623v1]` 처럼 arXiv ID 가 다른 인용 2개 이상)
  2. 과잉 일반화 표현(v3 검사와 같은 `_OVERGEN`: 모든 연구/논문/문서/방법 · 공통(된|으로|적|점) · 모두 … 공유/같/일치/보여)
- 지운 뒤 인용 단 문장이 하나도 안 남으면 **원래 결론 그대로** 둔다(결론이 비지 않게).
- 상태 문자열: 탈락 사유 뒤에 ` · 묶기 N 지움`.
- 코드 `core/llm/conclusion_rewrite.py`(`drop_bundled`), 테스트 `tests/unit/test_conclusion_rewrite.py`.

## 2. 방법 — 오프라인 (맥미니, LLM 호출은 v2 다시 쓰기뿐)

- 답: conclusion_v3_1024 와 같은 `pb1_real40` · `pb1_real2` 대상 45 답(v2 결과는 `conclusion_v3_1024/results.jsonl` 재사용, temperature 0) + `as0_m12`(조건 여러 개 질문 11) · `lf0_new`(3) 에 v2 를 새로 적용. 저장 답을 "원래 답"으로 보는 관례는 conclusion_v3_1024 와 같다.
- 그중 v2 가 바꾸지 못한 답에 규칙을 적용. 지울 문장이 있는 답이 판정 대상.
- **눈가림 판정:** 판정 대상 답의 **원래 결론 전체 문장**을 지울지 여부 표시 없이 내보내고(답 순서 섞음), Claude 가 인용 블록과 대조해 문장마다 라벨(O · E · X · U · F · ?, answer_judge_1024 정의)을 매긴다. 판정 뒤 규칙을 적용해 전 · 후를 센다.

## 3. 판정 (측정 전 고정)

| 지표 | 기준 |
|---|---|
| **주:** 답마다 결론의 (E + X) 문장 수 — 후처리 뒤 대 전 | 뒤가 적은 답 > 많은 답, 부호 검정 양측 p < 0.05 (지우기만 하므로 많은 답은 0 — 적은 답 ≥ 6 이어야 유의) |
| 보호: 지운 문장 중 정확(O) 비율 | ≤ 1/3 |
| 보호: 결론에 근거 결과(수치 + 인용, conclusion_rewrite_1021 `grounded`)를 잃은 답 | ≤ 1 |
| 보호: 지운 뒤 결론이 비거나 인용 0 | 0 (규칙상 보장, 확인만) |
| 보고: 규칙 적용 답 수, 지운 문장 수(규칙 1 · 2 별), 지운 뒤 첫 문장이 접속어("반면 · 또한 · 따라서 · 이러한")로 시작하는 답 수 | |

채택이면 사용자 승인 후 운영 `.env` `RAG_CONCLUSION_DROP_BUNDLED=1` + 봇 재시작.

## 5. 결과 (2026-10-25, 오프라인)

- 대상(본론이 논문 2편 이상 인용) 59 답 중 v2 가 못 바꾼 답 **11**(인용 없음 3 · 길이 4 · 문서 밖 숫자 3 · 한자 1).
- 그 11 답에 규칙을 적용해 **지운 답 0**. 판정할 것이 없어 주 기준(적은 답 ≥ 6) 미달 → **기각**. 코드는 `RAG_CONCLUSION_DROP_BUNDLED` 기본 0 으로 남긴다(운영 영향 없음).
- 원인 ①: 원래 결론은 대개 문장마다 인용을 달지 않는다. 묶기 문장(C08 · M02 의 끝 문장 `[a][b]`)을 지우면 인용 문장이 안 남아 안전 규칙이 원래 결론을 그대로 둔다.
- 원인 ② — **출발점이 틀렸다:** conclusion_v3_1024 에서 두 결론이 같았던 Q14 · Q17 · Q18 · Q38 · Q39 · Q40 은 v2 상태가 **"바꿈"**이다. 저장 답(pb1)의 결론이 이미 운영 v2 로 다시 쓴 것이라 temperature 0 재적용이 같은 글을 냈고, v3 는 탈락해 그 글이 남았다. 즉 묶기 · 일반화 오류는 **검사를 통과한 v2 결론** 안에 있다(conclusion_v3_1024 §5 의 해당 문장 고침).

### 사후 탐색 (사전 등록 아님 — 같은 데이터, 다음 라운드의 근거로만)

conclusion_v3_1024 판정 라벨(`blind_judged.tsv`)로, v2 가 바꾼 33 답의 v2 결론에 같은 규칙을 적용하면(스크립트 `pp_explore.py`):

| | 값 |
|---|---|
| 규칙 적용 답 | 7 / 33 |
| E + X 가 줄어든 답 | 6 (늘어난 답 0, 지우기만 하므로) |
| 지운 문장 8 개의 라벨 | X 6 · E 1 · O 1 |

부호 검정으로는 6 : 0 (p = 0.031) 이지만 같은 데이터 · 판정자가 규칙을 아는 상태라 채택 근거가 아니다. **다음 라운드:** 검사를 통과한 v2 결론에도 같은 지우기를 적용 — 새 답(새 질문 또는 다른 세트)으로 사전 등록 · 눈가림 판정.
