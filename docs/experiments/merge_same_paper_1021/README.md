## 1. 바꾸는 것 — `RAG_MERGE_SAME_PAPER` (기본 `0`)

`1` 이면 RAG 답 후처리에서(인용 교정 뒤, 번호 다시 매기기 앞) 본론 항목 중 **논문 한 편만 인용한 항목**이 앞에 나온 항목과 **같은 한 편**이면:
- 뒤 항목의 머리(`N. <b>제목</b>:`)를 떼고 설명을 앞 항목 끝에 붙인 뒤 뒤 항목을 지운다. 번호는 기존 `renumber_body_items` 가 다시 매긴다.
- 인용이 없거나 두 편 이상인 항목은 건드리지 않는다.
- 코드: `core/llm/answer_fix.py` `merge_same_paper_items`, 테스트 `tests/unit/test_answer_fix.py`.
