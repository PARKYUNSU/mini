# 논문 단위 cross-encoder 재순위 — 오프라인 평가 (사전 등록, 2026-10-23)

> 측정 **전에** 쓴다. 출발점: final_select_1023 진단 — 운영에서 놓친 26문항 중 5문항은 **청크 하나짜리 정답**이 논문 점수(상위 청크 합 + 다중 근거 보너스)에서 30~86위로 밀렸고, 6문항은 5위 경계(점수 차 0.002~)다. 청크 개수와 무관하게 질문과 논문 전체(제목 + 초록)를 비교하는 재순위가 맞는 처방. arXiv 2610.29722(LASAGNA) 재순위 20종 비교에서 `cross-encoder/ms-marco-MiniLM-L-6-v2` 가 1위(+0.043 NDCG@10), bge-reranker-v2-m3 · LLM listwise 는 손해. 반대 근거: SciRet(lit_review_1014) — MS MARCO cross-encoder 가 과학 코퍼스에서 정밀도를 떨어뜨림. 그래서 그대로 켜지 않고 섞는다.

## 1. 바꾸는 것 (오프라인만 — 운영 코드 변경 없음)

`production_retrieval_debug_for_eval(fetch_n=100)` 의 논문 순위(운영 점수) **상위 30편**에 대해 `CrossEncoder(ms-marco-MiniLM-L-6-v2)` 로 (영어 검색어 `rag_queries[0]`, 제목 + 초록 앞 1,500자) 점수를 매긴다.
- **주 처리 `rrf`:** 운영 순위와 CE 순위를 RRF(k = 60)로 합친 순위.
- 보조 `ce`: CE 점수만으로 매긴 순위(보고만, 판정에 쓰지 않는다).
- 대조 `base`: 운영 순위 그대로.

## 2. 세트

- 특정 논문 질문: `s18_162` 159 · `as1_real40` 34 · `as1_real2` 34 (final_select_1023 과 같은 검색어 · 정답).
- 주제형(보고): `corpus_seed_1023` R01–R04, `aspect_split_1022` 12문항 × 조건 24.

## 3. 판정 (측정 전 고정)

| 지표 | 기준 |
|---|---|
| **주:** 특정 논문 질문 227문항 중 상위 5편에 정답이 든 문항 — `rrf` 대 `base` | `rrf` 가 늘고 McNemar 양측 p < 0.05 |

통과하면 운영 반영 라운드(답 재생성 · 응답 시간 · light rerank 와의 관계 확인)를 따로 사전 등록한다 — 이 라운드는 운영을 바꾸지 않는다.

한계: `base` 는 디버그 순위(light rerank · 제목 주입 · 목록 모드 재검색 · 관련 문서 거르기 전)다.

**읽은 것**

## 6. 2차 — 범위 상위 100편 (사후 라운드, 사전 등록 2026-10-23)

> 1차 결과(§5)를 보고 정했다 — 사후다. 1차는 청크 하나짜리 정답 5건(운영 순위 31~86위)에 설계상 닿지 못했다.

- **바꾸는 것:** 다시 매기는 범위 `TOP` 30 → **100**. 나머지(모델 · 입력 · RRF k = 60 · 세트 · 검색어)는 1차와 같다. 대조는 1차와 같은 `base`.
- **판정(측정 전 고정, 1차와 같은 기준):** 주 — 227문항 상위 5 안 정답 `rrf` 대 `base` McNemar 양측 p < 0.05 · 보호 — 잃은 문항 ≤ 3 · CE 점수 시간(100편) 중앙 ≤ 1.5s. 보고 — `ce` 단독, 상위 10, 청크 하나짜리 5 · 경계 4 회복, 주제형 R01–R04 · M12, 1차(30편)와의 차이.
