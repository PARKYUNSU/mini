## 3. 결론

- 글자 겹침 규칙은 전제 새어 듦을 가르지 못한다(dev 1/8, 새어 들지 않은 문장 5). held-out 사전 등록은 하지 않는다. R4 초안은 접는 쪽을 제안한다.
- 전제 새어 듦 자체는 전제 질문에서 흔하다(23%). 주로 답 단계에서 들어온다.
- 막으려면 글자 대신 내용 대조가 필요하다. 예: 질문의 전제 절을 뽑아 9B 가 컨텍스트와 대조하고, 안 맞으면 고지한다. 이것은 새 설계라 따로 정한다.
- 이 30문항과 답은 dev 다. 전제 확인 라운드를 하면 held-out 은 새 전제 질문으로 쓴다. 지금 held-out F 꼴은 9문항뿐이다.
