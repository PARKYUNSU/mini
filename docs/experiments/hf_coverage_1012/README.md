# 주목 논문 수집 — HF Daily Papers 를 수집원에 넣기 (사전 등록, 2026-10-12)

> 측정 **전에** 쓴다. §3 판정 규칙은 결과를 본 뒤 바꾸지 않는다.

## 1. 문제

- 일일 수집(스케줄러 01:00)은 `cs.AI` **최신 제출 20편**을 기계적으로 받는다 — 하루 제출 ~500편 중 4%, 주제·중요도와 무관.
- 측정(2026-10-12): Hugging Face Daily Papers(커뮤니티가 고른 주목 논문) 중 코퍼스에 있는 비율 **2026-06 23/892 (2.6%)**, 일별 상위 10편 3/220. 데몬이 정상인 2026-10-07~11 도 17/150 (11.3%).
- 2026-05-29 ~ 10-06 은 스케줄러 데몬이 돌지 않아 아예 비었다(감시 알림은 별도로 추가 — `apps/telegram_bot/ingest_watchdog.py`).

## 2. 바꾸는 것

1. 수집원 추가 — [`pipelines/ingest/hf_daily.py`](../../../pipelines/ingest/hf_daily.py): 날짜 D 의 HF Daily Papers 를 추천 수 순으로 상위 N편 골라 arXiv `id_list` 로 메타를 받고, 기존 파이프라인과 같은 PDF → 파싱 → JSONL → Chroma 로 넣는다(중복은 건너뜀).
2. 일일 수집: 01:00 에 어제의 HF 상위 20편 + `cs.AI` 최신 10편(현행 20 → 10).
3. 백필: 2026-05-29 ~ 10-06 은 HF 상위 15편/일(무작위 `cs.AI` 백필은 2026-05-17 까지 하고 중단).

## 3. 평가 (사전 선언)

- **질문 세트** `hf_june40`: 2026-06 HF Daily 일별 상위 10편 중 **현재 코퍼스에 없는** 논문에서 시드 0 으로 40편, 제목·초록으로 한국어 질문 1개씩(`gen_hf_questions.py`, `qwen3.5:9b`, v12 질문 생성 프롬프트와 같음). 측정 전에 고정·커밋.
- 지표: 질문마다 운영 검색(라우터 → RAG → 번호 매기기, `eval_e2e_ko.py --questions … --gold …`, 답변 스텁)에서 **정답 논문이 컨텍스트에 들어오는가**.
- 측정 시점: (전) 지금 · (후) 6월 HF 백필 뒤. 같은 질문·같은 코드.
- **채택**: 후의 적중이 전보다 McNemar 양측 α=0.05 로 유의하게 높고, **가드** — 기존 평가 162문항의 컨텍스트 적중이 138 에서 유의하게 떨어지지 않을 것(같은 검정).
- 예상: 전 ≈ 0/40 (코퍼스에 없는 논문만 골랐으므로), 후 ≥ 30/40.

이 측정은 "수집한 논문이 검색에 실제로 잡히는가"를 확인하는 것이다 — 전이 0 에 가까운 것은 설계상 당연하고, 확인할 것은 후의 적중률과 기존 문항 가드다.
