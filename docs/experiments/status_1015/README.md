## 2. 보고할 것

1. **답변 정확도 (162)**: `now_162` 대 `ans_v13_db2`, 컨텍스트 논문이 같고 정답이 컨텍스트에 있는 문항만 짝으로. **Claude 눈가림 짝 판정**(answer_quality_1010 §6 과 같은 기준·형식: `build_blind_pairs.py` → 판정 → `analyze_blind_pairs.py`) — correct · ok · wrong · 날조, McNemar(양측). 판정자에 따라 절대값이 달라지므로 **짝 차이를 주로**, 각자의 비율은 참고로 적는다.
2. **정답 없음 처리**: `nogold_metrics.py now_162 ans_v13_db2` — 일관 고지, 거짓 부정.
3. **실제 사용형 (real40)**: `score_real_eval.py now_real40 real_gate real_v13` — 수치(N) 정답, 비교(C) 두 편 검색·인용, 목록(T) 정답 인용 수.
4. **검색**: 162 `ok`, real2 34 `ok`.
5. **전체 응답 시간**(답변 포함, 문항당 `elapsed`): 중앙값 · 90번째 · 최대, 유형별(비교 질문 따로). 대조 `ans_v13_db2` 중앙값 69.6s.
6. 한자 섞임, 답 길이.

## 3. 해석 규칙 (미리 정함)

- 이것은 위치 측정이다 — 결과로 운영을 바꾸지 않는다. 나빠진 지표가 있으면 원인을 따로 사전 등록해서 본다.
- 컨텍스트가 다른 문항은 답변 짝에서 뺀다(검색이 바뀐 효과와 답변 효과가 섞인다). 뺀 수와 그 문항의 검색 `ok` 변화는 따로 적는다.
- 성적표는 이 결과로 다시 쓴다. 10-13 수치와 다른 판정에서 나온 값은 섞지 않는다.
