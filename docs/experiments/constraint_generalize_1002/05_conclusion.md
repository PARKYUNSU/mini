# 05. 결론 — 판정 불가. 다만 옆에서 더 큰 것이 보였다

측정 2026-10-02 12:43 → 16:14 (210분). [`scripts/eval_trio_round.sh`](../../../scripts/eval_trio_round.sh) `yunsur_v9 yunsur_v10 gen126`, 커밋 `bdcf6eb`, 126문항 sha256 `ce4a7fa0acfa`, 반복 3회, 세 모델 1,134시행. 원본 [`04_eval/`](04_eval/).

## 판정 ([§4](README.md#4-판정-사전-선언--결과를-본-뒤-바꾸지-않는다) 그대로)

```
판정 대상 — 비길이 제약 24문항 통합, v9 vs v10
  둘 다 실패 10 · v9만 4 · v10만 1 · 둘 다 통과 9
  → 불일치 5쌍 (기준 6 이상) → 판정 불가
```

**24문항 중 19개가 두 모델을 가르지 못했다.** 사전 기대는 "일반화되지 않는다" 였지만, **그 예측이 맞았다고 말할 수 없다** — 못 쟀기 때문이다. §4 가 이 구분을 요구한다.

난도 보정을 네 번 했고 마지막은 3회 파일럿으로 했는데도 빗나갔다. **은퇴 모델(v5·v6)에서 맞춘 난도가 v9·v10 에 옮겨지지 않았다.** 파일럿 모델과 측정 모델이 다르면 난도도 다르다 — 당연한 말인데 설계에서 놓쳤다.

## 그런데 base 와의 비교에서 다른 것이 나왔다

| 비교 (비길이 24문항) | 앞만 실패 : 뒤만 실패 | 불일치 | p |
|---|---|---|---|
| v9 : v10 | 4 : 1 | 5 | 0.375 |
| base : v10 | **0 : 4** | 4 | 0.125 |
| **base : v9** | **0 : 7** | 7 | **0.016** |

**base 가 7문항에서 이기고 한 번도 지지 않았다.** 비길이 제약에서 **v9 은 base 보다 유의하게 나쁘다.** v10 도 같은 방향(0:4)이고 진 적이 없다.

**이것은 사전 등록한 가설이 아니다 — 탐색적 관찰이다.** `base : v9` 비교는 §4 의 판정 대상이 아니었고, 이 라운드는 그것을 검정하도록 설계되지 않았다. 확정하려면 **그 가설로 사전 등록해 새 문항에서 다시 재야 한다.**

그래도 기록할 가치가 있다. 지금까지 일곱 라운드가 "파인튜닝이 base 를 해치지 않는다" 를 반복해 확인했는데 ([`../README.md`](../README.md)), **그것은 옛 문항이 그 손상을 볼 수 없었기 때문일 수 있다.** 잡담·계획에서 base 가 0% 였으므로 더 나빠질 자리도 없었다.

## 길이 효과는 세 번째로 재현됐다

같은 세션의 길이 제약 16문항([`../planner_signal_0929/`](../planner_signal_0929/) 의 `planner_33`~`48`):


| 세션 | v9만 : v10만 | p |
|---|---|---|
| 2026-10-01 오전 | 10 : 2 | 0.039 |
| 2026-10-01 저녁 | 8 : 0 | 0.008 |
| **2026-10-02 낮** | **8 : 0** | **0.008** |

**세 세션 연속이고 v10 이 진 적이 없다.** [`../protocol.md`](../protocol.md) §3 의 결론이 한 번 더 지지됐다.

## 그래서 지금 그림

| 제약 | v9 vs v10 | base vs 파인튜닝 |
|---|---|---|
| **길이** (줄당 글자 수) | **v10 이 낫다** (3세션, p≤0.039) | base : v10 은 유의하지 않음 |
| **비길이** (줄 수·어휘) | 구분 안 됨 (판정 불가) | **base 가 낫다** (v9 p=0.016 · v10 방향 동일) |

lr 인하는 **길이 제약에만** 작용하고, 파인튜닝 자체는 **비길이 제약을 깎는** 것으로 보인다. 둘 다 옛 54문항으로는 볼 수 없던 것이다.

## 한계

1. **주 판정은 판정 불가다.** 일반화 여부에 답하지 못했다.
2. **`base : v9` 는 탐색적이다.** 사전 등록되지 않았고 다중 비교 보정도 없다. 같은 라운드에서 여러 쌍을 보면 우연히 유의한 것이 나올 수 있다.
3. **난도 보정이 실패했다.** 은퇴 모델로 맞춘 난도가 비교 대상에 옮겨지지 않았다 — 24문항 중 19개가 양 끝이었다.
4. 어휘(계획) 8문항은 **둘 다 실패 5 · 불일치 0** 으로 완전히 바닥이었다.
