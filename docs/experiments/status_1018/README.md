## 2. 보고할 것

1. **답변 정확도 (162)**: `s18_162` 대 `now_162`, 컨텍스트 논문이 같고 정답이 컨텍스트에 있는 문항만 짝. Claude 눈가림 짝 판정(status_1015 와 같은 기준 · 관대 날조 기준) — correct · ok · wrong · 날조, McNemar. 선택: 같은 답을 gpt-oss-120b 단일 답변 판정으로 재확인(abstract_full_1016 §7 과 같은 방식, RunPod — 사용자 확인 후).
2. **정답 없음 처리**: `nogold_metrics.py` — 일관 고지, 거짓 부정.
3. **실제 사용형 (real40 · real2)**: `score_real_eval.py` — 수치 N 정답, 비교 C 두 편 검색·인용, 목록 T 정답 인용 수 · ≥ 3 문항.
4. **검색**: 162 · real40 · real2 `ok`.
5. **응답 시간**(문항당 `elapsed`): 중앙 · p90 · 최대, 유형별(수치 · 비교 · 목록 따로).
6. 한자 섞임, 답 길이, 생성 잘림(측정 시간대 Ollama 로그 `truncated = 1`).
