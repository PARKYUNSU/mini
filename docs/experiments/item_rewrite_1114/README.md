# item_rewrite_1114 — 본론 항목을 문서마다 따로 다시 쓰기 (사전 등록, 2026-11-14)

> 측정 **전에** 쓴다. depth_1114(답 틀 바꾸기, 미달)의 다음 단계.

## 0. 왜
- depth_1114: 답 틀로 "방법 → 결과 → 조건" 을 시켜도 v13 은 항목을 1–2 문장으로 쓴다(쌍 15:17).
- 사전 점검(11-14): 일반 답 컨텍스트에는 이미 **초록 전체**(`RAG_ABSTRACT_CHARS=2000`)가 들어간다 → 결과 문장 뽑아 넣기(RAG_LIST_FINDINGS 방식)는 정보를 늘리지 않는다. 재료는 있는데 한 번의 답 호출에서 여러 논문을 짧게 쓴다.
- 결론 다시 쓰기(conclusion_rewrite_1021)처럼 답을 낸 뒤 **항목마다 따로** 짧은 호출로 다시 쓰면, 모델은 한 논문만 보고 3–4 문장을 쓸 수 있다.

## 1. 바꾸는 것 (`RAG_ITEM_REWRITE=1`, 기본 0, `core/llm/item_rewrite.py`)
- 대상: 목록 모드가 아닌 답의 본론 항목 중 한 줄짜리이고 인용 논문이 하나(같은 논문 여러 번 포함)이며 그 블록이 컨텍스트에 있는 것. 앞에서 최대 `RAG_ITEM_REWRITE_MAX`(기본 4) 항목.
- 항목마다 답 모델(v13)에 질문 · 그 논문 블록(≤2,500자) · 지금 항목을 주고 3–4 문장으로 다시 쓰게 한다: ① 무엇을 제안 · 조사했는지 ② 핵심 결과(문서 숫자 그대로) ③ 평가 대상 · 조건 · 한계(문서에 있을 때만) ④ 질문과의 관계.
- 바꾸는 조건(하나라도 어기면 원래 항목 유지): 길이 80–700자 · 한자 없음 · 숫자는 그 블록에 그대로 있을 것(body_numbers 와 같은 검사) · 원래 항목보다 길 것.
- 항목 머리(`N. <b>이름</b>:`)와 인용 `[ID]` 는 코드가 붙인다. 위치: 본론 숫자 대조(RAG_BODY_NUM_CHECK) 바로 앞.
- '없음' 판정 답(관련 연구 표시 대상)도 그대로 적용 — 표시는 뒤에서 붙는다.
