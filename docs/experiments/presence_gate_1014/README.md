## 1. 바꾸는 것

`RAG_PRESENCE_GATE=1` (기본 `0`) 이면 `core/llm/presence_judge.should_judge` 가 질문이 아래 규칙에 걸릴 때 **판정 호출·정답 없음 힌트를 건너뛴다** (답변 모델·프롬프트는 그대로).

- 수치: `몇 %/배/개/…`, `얼마나`, `정확도가`, `성공률`, `수치`, `N%`
- 비교: `차이`, `비교`, `어떻게 달라`, `뭐가 달라`, `다른 거야`, `vs`, `A랑/와 B … 달라`
- 목록: `논문들`, `연구들`, `동향`, `정리해`, `트렌드`, `N개 찾/알려`, `목록`, `방향으로 가`

걸리는 문항(측정 전 셈): 162 중 **4**(A015·A054·A090·C1_02, 그중 정답 없음 C1_02 1개) · 실제 사용형 40 중 **36**(R01·R03·R04·R05 제외).

- 대조: `real_v13`(10-14 08:46–10:22, 같은 DB 데이터 — 그 뒤 수집 없음), `ans_v13_db2`(162).
- 짝은 `context_papers` 가 같은 문항만.

## 3. 채택 규칙

| 지표 | 기준 |
|---|---|
| **주:** 실제 사용형 N·C·T 중 정답이 컨텍스트에 있는 문항의 '없다' 답 | 처리 < 대조, McNemar 양측 p < 0.05 |
| 실제 사용형 N 수치 정답 (자동) | 처리 ≥ 대조 − 1 |
| 162 정답 없음 일관 고지 | 잃는 것 ≤ 1 (C1_02) |
| 162 게이트 4문항 거짓 부정 | 늘지 않음 |

채택이면 **사용자 승인 후** 운영 `.env` `RAG_PRESENCE_GATE=1`.

예상: 실제 사용형 '없다' 8 → 0~2 (p ≈ 0.008~0.03). 수치 정답 7 → 10 안팎(판정 때문에 놓친 5개 중 일부 회복).
