- 수치: `몇 %/배/개/…`, `얼마나`, `정확도가`, `성공률`, `수치`, `N%`
- 비교: `차이`, `비교`, `어떻게 달라`, `뭐가 달라`, `다른 거야`, `vs`, `A랑/와 B … 달라`

**대가 (정답이 컨텍스트에 없는 실제 사용형 11문항, 사전 기준 밖 — 관찰)**
- 판정이 꺼지자 v13 이 **자기 말로** "참고 문서에는 … 포함되어 있지 않습니다"라고 밝히는 경우가 많다(N04 · N07 · C03 · C06 · C08 · C09). C02 · C10 은 두 방법 항목을 "(관련 문서 없음)"으로 비우고 결론에서 "언급하지 않아 차이를 설명할 수 없다"고 답한다.
- **C07(Reasoning-SQL vs Solid-SQL)만 서론에서 근거 없이 "핵심 차이는 …"을 단정**하고, 결론에서는 "Solid-SQL 은 언급되어 있지 않다"고 인정한다 — 부분 날조 1/11.
- 즉 게이트의 대가는 "없는데 지어냄" 1/11 정도로 작다. 비교 질문 검색(두 편 모두 3/11)이 나아지면 더 준다 → 방법 이름별 제목 매칭(lit_review_1014 §5 제안 4)이 다음 후보.
