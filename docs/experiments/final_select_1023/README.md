# 최종 선택 진단 — 정답 논문은 어느 단계에서 밀리나 (진단, 2026-10-23)

> 채택 판정이 아니라 **위치 측정**이다. 출발점: hype_1014 §진단("병목은 recall 이 아니라 마지막 논문 단위 재순위") 이후 미뤄 둔 "최종 선택 진단", 그리고 이번 주 세 라운드(paper_blocks · aspect_split · corpus_seed)가 같은 결론("DB 에 있는데 순위에서 밀린다")으로 끝난 것.

## 방법

`diag.py`(맥미니, LLM 없음): 질문마다 저장된 검색어(`rag_queries[0]`)로 `production_retrieval_debug_for_eval(fetch_n=100)` — 운영과 같은 후보 풀 · 청크 점수 · 논문 집계 · 제목 보정(light rerank · 제목 주입 · 관련 문서 거르기 · 목록 모드 제외). 정답 논문의 논문 순위와 점수 항목을 `diag.jsonl` 에 남겼다. 세트: `s18_162`(10-18 운영 설정으로 잰 컨텍스트), `as1_real40` · `as1_real2`(10-22 운영과 같은 설정).

**운영에서 놓친 26문항의 원인 갈래**
1. **점수는 상위인데 운영 컨텍스트에서 빠짐 (8)** — s18 A023(2위) · A085 · C1_06 · C1_24 · C2_13(1위) · A098 · A114 · C2_10 · C2_03(3~4위), real2 T06(2위). s18 은 라우터가 논문 3편만 가져오던 설정이라(paper_blocks_1022 전) 4~5위가 잘렸고, 1~2위가 빠진 것은 light rerank · 목록 모드 재검색 · 관련 문서 거르기 쪽이다(real2 T06: 목록 질문 → 다른 검색어 10편 → 거르기).
2. **청크 하나짜리 정답이 논문 점수에서 밀림 (5)** — A039(68위) · A044(86위) · A106(35위) · C2_09 ReAct(62위) · C2_19 Mixtral(31위): 모두 **풀 안 청크 1개**. 논문 점수가 상위 청크 여러 개를 더하고 다중 근거 보너스를 주는 구조라, 한 청크만 맞는 논문이 여러 청크가 맞는 주변 논문에 밀린다.
3. **6~30위 경계 (6)** — A056 · A092(6위, 5위와 점수 차 0.002~0.003) · C1_22 · C2_06 LoRA · real40 T06 등.
4. **풀에 없음 (3)** — A112 · C2_20 · real40 N04.
5. **경로 문제 (1)** — real2 N07: 논문 점수 1위인데 컨텍스트가 비었다(그 회차는 RAG 경로를 타지 않음 — pb1 회차에서는 맞음). 검색이 아니라 라우팅.

**읽은 것**
- 지금 평가 세트(특정 논문을 묻는 질문 위주)에서 운영 검색은 이미 잘 맞는다(real 두 세트 64/68). 남은 놓침은 한 원인이 아니라 갈래가 다섯이다.
- 재순위로 고칠 수 있는 것은 **2번(청크 하나짜리 정답)** 과 **3번(경계)**: 질문과 논문(제목 + 초록)을 통째로 비교하는 논문 단위 재순위는 청크 개수에 영향받지 않는다. arXiv 2610.29722(LASAGNA) 재순위 비교에서 ms-marco-MiniLM-L6 cross-encoder 가 20종 중 1위(+0.043 NDCG@10), bge-reranker-v2-m3 · LLM listwise 는 손해.
- 이번 주 외부 리뷰 사례(주제형 질문: "순서나 개수", "중간 정보")는 이 평가 세트에 정답 목록이 없어 이 진단에 들어 있지 않다 — 주제형 질문의 순위 문제는 별도로 재야 한다.
