**읽은 것**
- light rerank 는 **논문 찾기형(162)에는 이롭고, 수치·비교·목록형(real40)에는 해롭다.** 비교 질문에서 두 편 모두 검색 3/11 이던 원인 중 하나가 이 재정렬이었다(키워드 검색어 하나와 논문 하나의 코사인으로 다시 줄을 세우면, 질문이 두 대상을 가리킬 때 한쪽만 남는다).
- 사전 규칙대로 운영은 켬 유지.
- **다음 가설 (사후에 나온 것 — 낙관 편향 있음):** 질문 유형 게이트(`presence_judge.gate_types`)에 걸리는 질문에서만 light rerank 를 끈다. 162 는 게이트 4문항뿐이라 거의 그대로, real40 은 끈 쪽 결과에 가까울 것. **real40 은 이미 본 데이터라 확인용 새 실제 사용형 질문 세트가 필요하다.**
