## 1. 바꾸는 것 (`RAG_DEPTH_TEMPLATE=1`, 기본 0)
- 일반 틀(`RAG_OUTPUT_TEMPLATE_MULTI_STRICT`) 대신 `RAG_OUTPUT_TEMPLATE_DEPTH`: 항목 꼴(`N. **이름**: … [문서 N]`)은 그대로(후처리 호환), 항목 안을 **방법 1문장 → 결과 1문장(문서에 나온 수치 · 비교를 그대로, 없으면 생략) → 조건 · 한계 1문장(문서에 있을 때만)**. 결과 숫자는 참고 문서에 있는 것만.
- 목록 질문 틀(RAG_LIST_SLOTS) · '없음' 힌트 답은 그대로.

## 2. dev 측정 (측정 전 고정)
- 세트: real40 40 + 점검 25(`blind_check_1113`) = 65 문항, 답까지(`--answer`). 대조 `dp0_*` · 새 `dp1_*` 를 같은 시간대에 번갈아 돌린다(코드 · 코퍼스 같음, 플래그만 다름).
- **주 지표**: 두 답이 다른 문항을 무작위 순서 · 조건 가림으로 쌍 비교(판정자 Claude 1 명, 질문 · 두 답 · 인용 문서 초록을 봄). 기준: "질문에 대해 논문의 방법 · 결과 · 조건을 더 구체적으로 알려 주는 쪽. 단 문서와 맞지 않는 내용이 있으면 그쪽이 진다." **새 나음 > 나쁨, 부호 검정 p < 0.05.**
- **보호** (하나라도 넘으면 미달):
  - P1 본론 숫자 중 컨텍스트에 없는 것(기계): 새 ≤ 대조 + 2
  - P2 쌍 비교에서 문서와 맞지 않는 내용이 있는 답: 새 ≤ 대조 + 1
  - P3 real40 정답 인용: 새 ≥ 대조 − 2
  - P4 판정 '없음' 답(판정 호출이 답 프롬프트 앞부분을 같이 씀): 새 ≤ 대조 + 2
  - P5 한자 섞인 답: 새 ≤ 대조 + 2
  - P6 문항 시간 중앙: 새 ≤ 대조 + 10s (기억 추출을 안 멈춘 측정 — 두 조건 같은 조건)
- 보고만: 기준선 지표(항목 길이 · 문장 수 · 수치 든 항목 · 초록 수치 빠짐), 틀을 따른 비율.
- **dev 통과는 채택 근거가 아니다** → held-out 120(`judge_v2_1113/heldout120.tsv`) 같은 방식 사전 등록 · 측정 → 운영 승인 요청. 미달 → 접고 보고.
