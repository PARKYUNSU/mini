# 관련 문서가 1편만 남은 답도 DB 밖(OpenAlex)을 찾아보기 — 오프라인 평가 (사전 등록, 2026-10-23)

> 측정 **전에** 쓴다. 출발점: 외부 리뷰(10-22 18:26 "검색 문서 순서나 개수 …", 65점) — 관련 문서 거르기 뒤 1편만 남았는데 밝히지 않았고 핵심 논문이 빠졌다. 지금 외부 검색(`RAG_EXTERNAL_SEARCH=1`, external_search_v3_1020)은 정답 유무 판정 '없음' 또는 목록 질문에만 돈다 — 이 답은 판정 = 문서 1 · 목록 아님이라 돌지 않았다. relevance_filter_1022 · paper_blocks_1022 측정에서 1편만 남은 답이 74 중 23~29개다.

## 1. 바꾸는 것 — `RAG_EXTERNAL_ON_SINGLE` (기본 `0`)

`1` 이면 외부 검색 조건에 "번호표 논문(관련 문서 거르기 뒤)이 **1편**"을 더한다. 나머지(OpenAlex v3 검색어 · 유사도 문턱 · 답변과 동시 실행 · "DB 밖에서 찾은 관련 논문" 덧붙이기 · 후보 기록)는 그대로. 코드 `core/graph/agent_nodes.py`.

## 2. 방법 — 오프라인 (OpenAlex 호출만, 답 재생성 없음)

aspect_split_1022 의 처리 쪽 저장 결과(`as1_real40` · `as1_real2` · `as1_m12`, 운영과 같은 설정: 관련 문서 거르기 · 논문 단위 블록 포함)에서 **번호표 논문이 1편**이고 목록 질문이 아닌 답 전부에, 그 답의 검색어로 `search_openalex`(운영과 같은 인자)를 부른다. 결과 논문마다 Claude 가 제목 + 초록으로 3단계 판정(external_search_v3_1020 과 같음): 2 질문에 직접 답하는 연구 · 1 같은 주제지만 질문 조건과 다름 · 0 무관. 스크립트 `offline.py`, 결과 `items.jsonl` · `judged.tsv`.

## 3. 판정 (측정 전 고정) — external_search_v3_1020 과 같은 기준

| 지표 | 기준 |
|---|---|
| **주 1:** 대상 답 중 외부 결과에 '2' 가 1편 이상 | ≥ 50% |
| **주 2:** 덧붙는 논문 중 '0'(무관) | ≤ 30% |
| 보호: OpenAlex 실패(오류 · 6s 초과) | ≤ 10% |
| 보고: 대상 수, 결과가 0편인 답 수, 수치(N) 질문만 따로 | |

두 주 지표를 **모두** 만족하면 채택 후보 → 사용자 승인 후 운영 `.env` `RAG_EXTERNAL_ON_SINGLE=1` + 봇 재시작.
