# RAG 컨텍스트에 논문 초록 넣기 (사전 등록, 2026-10-11)

> 측정 **전에** 쓴다. §3 판정 규칙은 결과를 본 뒤 바꾸지 않는다.

## 1. 왜

[presence_judge_1011 §6.5](../presence_judge_1011/README.md): 정답 논문이 컨텍스트에 들어와도 그 블록의 **78% 에 초록이 없다.** 검색은 청크 단위라 방법론 일부·관련 연구·저자 목록 같은 발췌가 그 논문 이름으로 들어온다. 예: A003 정답(Symbolic Learning) 블록은 관련 연구의 DSpy 설명이었고, v12·v13 은 DSpy 를 그 논문의 기여로 썼다(교차 귀속). 초록 있는 블록 쪽 답변 ok 가 90% vs 79% (p 0.20, 비등록) 로 같은 방향이었다.

## 2. 바꾸는 것 — 하나

`core/rag/agent_chroma_rag._format_chroma_hits`: 블록 본문에 그 논문의 초록이 들어 있지 않으면, 머리(`[ID] 제목`) 바로 뒤에 `[초록] <초록 앞 800자>` 를 넣고 그 뒤에 원래 발췌를 둔다. 초록은 Chroma 메타데이터(`abstract`).

- 환경 변수 `RAG_CONTEXT_ABSTRACT=1` 일 때만 켠다(기본 꺼짐). **이 측정 동안 운영은 그대로.**
- 800자: 현재 컨텍스트(중앙 2,735자, 최대 3,274자)에 더해도 다중 문서 경로의 `rag_max_chars=8000` 안에 들어온다(추정 최대 ≈ 7,400). 길이 상한·검색·번호 매기기·답변 모델(`yunsur_v13`)·후처리는 바꾸지 않는다.
- 검색 결과(어떤 논문이 들어오는가)는 바뀌지 않는다 — 형식만 바뀐다. `context_papers` 가 `ans_v13` 과 같은지 확인한다.

## 3. 평가 (사전 선언)

생성: `RAG_ANSWER_MODEL=yunsur_v13 RAG_CONTEXT_ABSTRACT=1 eval_e2e_ko.py --answer --save-context --label ans_v13abs` (162문항). 비교 대상: 이미 있는 `ans_v13`(같은 모델, 초록 없음).

- **주 지표 — 내용**: gpt-oss-120b 단일 답변 판정(`judge_answers.py --base-url`, RunPod H100) → `compare_judged_pairs.py ans_v13abs ans_v13`. `ans_v13` 판정은 이미 있는 `judged_gptoss_ans_v13.jsonl` 을 쓴다(같은 판정자·프롬프트·설정).
  - **채택**: ok 가 유의하게 높다, **또는** ok 차이가 유의하지 않고 날조가 유의하게 낮다 (McNemar 양측 α=0.05).
  - **실패**: ok 가 유의하게 낮거나 날조가 유의하게 높다.
  - 그 밖은 **보류**.
- **가드 — 거짓 부정**: `nogold_metrics.py ans_v13abs ans_v13` 에서 거짓 부정이 5% 이하이고 v13 보다 유의하게 늘지 않을 것. 어기면 채택하지 않는다.
- 부 지표(서술): correct 짝, 첫 항목 정답률, 정답 없음 일관 고지, 컨텍스트 길이(최대 ≤ 8000 확인), 초록이 붙은 블록 비율, 판정 호출(`presence_judge.py --model yunsur_v13 --ctx ans_v13abs`)의 거짓 '없음'·재현(§3 기준과 비교).

예상: 교차 귀속이 줄어 날조가 감소하고 ok 는 같거나 오른다. 판정 호출의 거짓 '없음'은 줄어든다.

## 3.5 결과 (2026-10-12)

생성 `ans_v13abs` 162문항(RAG 159), 컨텍스트 논문이 `ans_v13` 과 159문항 모두 같음. 컨텍스트 길이 중앙 6,479 · 최대 7,309자(≤ 8000 ✓). 블록 780개 중 698개(89%)에 `[초록]` 이 붙음(나머지는 발췌에 이미 초록).

| 정답 있음 138쌍 (gpt-oss) | v13 + 초록 | v13 |
|---|---|---|
| **ok** | **127** | 112 |
| correct | 48 | 16 |
| wrong | 9 | 22 |
| absent | 2 | 4 |
| **날조** | **22** | 40 |

- **ok 짝: 초록만 21 · v13만 6 → McNemar p = 0.006 (유의하게 높음).**
- **날조 짝: 초록만 14 · v13만 32 → p = 0.011 (유의하게 낮음).**
- **가드 — 거짓 부정**: 0/138 vs 0/138 ✓. 정답 없음 일관 고지 0 vs 0, 자기모순 0 vs 0.
- 첫 항목 정답 132 vs 127.

**사전 규칙(§3)에 따른 판정: 채택.** 판정 H100 Secure 약 10분 ≈ $0.7.

- 부 지표 — 판정 호출(`yunsur_v13`, 초록 컨텍스트): 거짓 '없음' **5/138 (3.6%)** · 재현 **13/21** · 정답 번호 96.4% · 10.8s/호출. 초록 없을 때(9.4% · 16/21 · 88.4%)는 presence_judge_1011 §3 기준 미달이었지만, **초록 컨텍스트에서는 기준(≤ 5% · ≥ 7/21)을 통과**한다 → presence_judge_1011 §3 의 다음 단계(판정 → 힌트 → 답변 통합 측정)로 갈 수 있다.

해석: 재학습 없이 컨텍스트 형식만 바꿔 correct 가 3배(16 → 48), wrong·날조가 절반으로 줄었다. 정답 블록이 관련 연구·방법론 조각뿐일 때 모델이 그 조각을 논문의 기여로 쓰던 교차 귀속이 주된 원인이었다는 해석과 맞는다.
