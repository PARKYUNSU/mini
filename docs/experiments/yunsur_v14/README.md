# yunsur_v14 — 정답 없는 RAG 예시를 7.5% → 15% 로 늘린다 (사전 등록, 2026-10-11)

> 데이터를 만들기 **전에** 쓴다. §3 판정 규칙은 결과를 본 뒤 바꾸지 않는다.

## 1. 문제 — v13 은 "없다"고 말하지 않는다

[yunsur_v13 §3.5](../yunsur_v13/README.md): v13 은 거짓 부정을 41 → 0 으로 없앴지만, 정답이 컨텍스트에 정말 없는 21문항에서도 "없다" 모드에 한 번도 들어가지 않는다(일관 고지 0/21; base 서론 1/21). 학습 RAG 400건 중 정답 없음 예시가 30건(7.5%)뿐이라, 정답 없음 형식을 뚜렷하게 만들자 모델이 그 모드를 사실상 고르지 않게 된 것으로 본다.

평가셋에서 RAG 문항 중 정답이 컨텍스트에 없는 비율은 21/159 = 13% 다. 학습 비율이 운영 비율의 절반 남짓이다.

## 2. 바꾸는 것 — 하나뿐: 정답 없음 비율

- RAG 400건 = **정답 있음 340 + 정답 없음 60 (15%)**. 총 크기는 유지.
  - 정답 없음 60 = v13 의 30건 그대로 + **새 30건**(같은 v13 형식·검증 — `teacher_v13_nogold.py`).
  - 정답 있음 370 → 340: v13 의 정답 있음 행 중 시드 0 으로 30건을 뺀다.
- 새 30건 프롬프트: 적격 정답 없음 프롬프트 109개 중 v12·v13 이 쓴 37개를 뺀 72개에서 시드 0 순서. 3회 실패하면 다음 것으로 대체(수 기록).
- 잡담 300·계획 400, 하이퍼파라미터, `MAX_SEQ_LENGTH=3072` — v13 과 같다. 행 순서는 v13 을 따르고, 빠진 정답 있음 30행 자리에 새 정답 없음 30행을 넣는다.
- 교사: RunPod H100 vLLM gpt-oss-120b (v13 과 같은 규칙·검증).

## 3. 평가 (사전 선언)

생성: `RAG_ANSWER_MODEL=yunsur_v14` 로 `ans_v14` 162문항(평가 프로세스에만). 후처리 전 원문. 컨텍스트가 `ans_v13` 과 같은 RAG 문항만 비교.

- **주 지표 — 정답 없음 고지**: 정답이 컨텍스트에 없는 문항에서 서론·결론 모두 "없다"인 비율, v13 과 짝 McNemar (양측 α=0.05). n≈21 이라 검정력이 낮다 — 한쪽만 고지한 쌍이 6:0 이상이어야 유의하다.
- **주 지표 — 거짓 부정 상한**: 정답 있는 문항에서 서론 "없다" 비율이 **5% 이하**이고, v13 대비 유의하게 높지 않다(McNemar).
- 부 지표(서술): 자기모순 수, 정답 없음 문항의 "없다" 어디든 수, 첫 항목이 정답 논문 비율.
- **안전 지표 — 내용**: v14 vs v13, gpt-oss-120b 단일 답변 판정(`judge_answers.py --base-url`) → `compare_judged_pairs.py`. ok 가 유의하게 낮지 않고 날조가 유의하게 높지 않을 것. 참고로 correct 짝도 서술한다(v13 에서 v12 대비 7:16, p 0.093 였음).

판정:
- **채택**: 정답 없음 고지가 v13 보다 유의하게 높다 **그리고** 거짓 부정 ≤ 5% 이며 v13 보다 유의하게 높지 않다 **그리고** 안전 지표 통과.
- **보류**: 고지 차이가 유의하지 않다 → v13 유지.
- **실패**: 거짓 부정 > 5% 또는 유의하게 증가, 또는 안전 지표 실패.

예상: 정답 없음 고지 0/21 → 6~10/21, 거짓 부정 0 → 1~3%. 정답 있음 학습 행이 30 줄어 correct 가 약간 내려갈 수 있다.
