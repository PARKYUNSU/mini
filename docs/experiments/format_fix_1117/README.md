## 1. 바꾸는 것
**A. `RAG_FORMAT_FIX=1`** (기본 0, `core/llm/format_fix.py`)
- 항목 다시 쓰기 · 결론 다시 쓰기(v2/v4) 프롬프트에 "영어 전문 용어(poisoning · judge · rater · chunking)는 소리대로 옮기지 말고 영어 그대로" 한 줄.
- 다시 쓴 항목에 한글 바로 뒤 라틴 소문자(`[가-힣][a-z]{2,}`, 예 `포izoning`)가 있으면 원래 항목 유지.
- 최종 답에 남은 한자 덩어리를 지운다.
- '없음' 판정 답에 (관련 연구) 항목이 있으면 고정 문장을 "질문을 직접 다룬 연구는 찾지 못했고, 가장 가까운 연구는 아래와 같습니다." · "따라서 질문을 직접 다룬 연구는 없지만, 위 관련 연구가 가장 가깝습니다." 로.

**B. `RAG_CONCLUSION_PROMPT=v4`** (A 위에, 지금 운영 v2)
- 결론 다시 쓰기를 "질문에 직접 답하는 2~3문장": 첫 문장은 질문에 대한 답(비교 질문이면 어느 쪽이 어떤 조건에서 나은지, 판단 못 하면 그렇다고) · 질문 조건(언어 · 문서 유형)을 문서가 안 다루면 밝힘 · 마지막 문장은 문서 결과에서 바로 나오는 실무 권고 · 같은 논문 한 문장 한 번 인용 · 방법 재설명 금지. 다시 쓰기 대상(인용 논문 2편 이상 · '없음' 아님)은 v2 와 같다.

## 2. 측정 (측정 전 고정)
- held-out: 이 폴더 `heldout30.tsv` — 새로 쓴 업무형 질문 30(비교형 K01–K08 · 조건 있는 질문 K09–K16 · 방법 조사 K17–K24 · 코퍼스에 없을 법한 것 K25–K30). 답을 보기 전에 썼다. 단발(`--answer --save-context`).
- 세 갈래, 코드 · 코퍼스 같음: 대조 `fc0`(운영 그대로) · `ff1`(A) · `ff2`(A + B). dev 10(`W01–W10`)도 같은 세 갈래로 돌려 사용자 회귀 보고에만 쓴다.

**A 판정 (`ff1` vs `fc0`)**
- 주(기계): 깨진 글자(한글 뒤 라틴 소문자 · 한자) 또는 '없음' 모순(본론에 (관련 연구) 항목이 있는데 "찾는 연구가 없습니다" · "찾을 수 없습니다" 고정 문장)이 있는 답 — 짝지은 비교로 **새만 깨끗 > 대조만 깨끗, 부호 검정 p < 0.05**. (모순 문장 교체는 결정적이라, 판정 '없음' 답이 충분하면 거의 확정적으로 줄어든다 — 보호가 핵심.)
- 보호: 두 답이 다른 문항 블라인드 쌍(판정자 Claude 1 명, 기준 "질문에 맞게 문서 근거로 답한 쪽, 문서와 맞지 않으면 진다") 새 나쁨 ≤ 새 나음 + 2 · 다시 쓴 항목 수(바꿈) 새 ≥ 대조 × 0.8(섞인 글자 거부가 다시 쓰기를 너무 막지 않는지) · 시간 중앙 ≤ +5s.
- 보고만: 소리대로 옮긴 용어(정규식으로 못 잡는 것, 쌍 판정 때 직접 셈).

**B 판정 (`ff2` vs `ff1`)**
- 주: 결론이 다른 문항 블라인드 쌍(질문 · 두 결론 · 인용 논문 초록 700자). 기준 "질문에 직접 답하는 쪽 — 비교 질문엔 비교 결론, 질문 조건을 문서가 안 다루면 밝힘, 본론 되풀이 · 같은 인용 반복 없이 짧게. 단 문서와 맞지 않는 내용이 있으면 진다." **새 나음 > 나쁨, 부호 검정 p < 0.05.**
- 보호: 결론에 문서와 맞지 않는 내용이 있는 답 새 ≤ 대조 + 1 · 시간 중앙 ≤ +10s.

- 통과한 갈래만 운영 켜기 승인 요청. 미달 갈래는 접고 그 코드 삭제.
