> 측정 **전에** 쓴다. 출발점: [`real_eval_1013/`](../real_eval_1013/) §5 — 실제 사용형 질문에서 판정 v1 이 78회 중 54회 `없음`, 정답이 컨텍스트에 있는데 '없다' 답이 N 5/13 · C 2/4. v1 은 "사용자는 특정한 연구 하나를 찾고 있다 … 결과와 맞지 않으면 없음" 을 전제한다.

## 1. 바꾸는 것

`core/llm/presence_judge.PROMPT_V2` (`RAG_PRESENCE_PROMPT=v2` 일 때만, 기본 v1). v1 대비:
- 판정 기준을 "질문에 답하는 데 **직접 필요한 연구**가 하나라도 있나" 로.
- 수치·결과·세부 질문: 그 연구가 있으면 번호 — 발췌에 수치가 안 보여도 `없음` 아님.
- 비교·목록·동향 질문: 해당 연구가 하나라도 있으면 번호.
- 특정 연구 찾기: v1 과 같은 규칙(주제만 비슷하면 `없음`).

## 2. 방법 (오프라인, 비용 없음)

`scripts/presence_judge_v2_eval.py` — 저장된 컨텍스트로 판정 호출만 v1·v2 각각 1회(운영과 같은 `yunsur_v13`, temperature 0, seed 0, reasoning off).
- **162 찾기형** `ans_v13_db2` (복구 DB, 운영 설정): 정답 있음 → 거짓 '없음', 정답 없음 → '없음' 재현.
- **실제 사용형** `real_v13`: N·C·T 중 정답이 컨텍스트에 있는 문항 → 거짓 '없음'.

## 3. 채택 규칙 (모두 만족 → 온라인 통합 측정으로)

| 지표 | 기준 |
|---|---|
| **주:** 실제 사용형 거짓 '없음' | v2 < v1, McNemar 양측 p < 0.05 |
| 162 정답 있음 거짓 '없음' | v2 ≤ 5% |
| 162 정답 없음 '없음' 재현 | v2 가 v1 보다 유의하게 낮지 않음 |

통과하면 답변까지 포함한 온라인 측정(162 + real40, `RAG_PRESENCE_PROMPT=v2`)을 따로 사전 등록 후 진행, 그다음 **사용자 승인 후** 운영 반영.
