# DB 에 없을 때 외부 검색으로 찾아보기 (2단계) (사전 등록, 2026-10-20)

> 측정 **전에** 쓴다. 선행: [`corpus_seed_1020/`](../corpus_seed_1020/) — 질문 단위로 미리 수집하면 그 질문에는 크게 듣지만(20 → 27/34), 같은 분야 새 질문에는 약했다(15 → 17/30). 새 질문마다 그때그때 범위를 넓히는 갈래를 붙인다. 사용자 승인(10-20).

## 0. 탐색 (사전 등록 전, `.cron/ax/proto*.py`)

| API | 맥미니에서 | 판단 |
|---|---|---|
| arXiv API (`export.arxiv.org`) | 15s 시간 초과 · 빈 응답(제한) 반복 — 10-20 수집 때도 38편 시간 초과 | 실시간 불가 |
| Semantic Scholar | 0.2s 이지만 키 없이 **429** | 불가 |
| **OpenAlex** `/works?search=` | **~1s**, 결과 관련성 좋음(문장 단위 인용 질문에 ALCE 2305.14627 등) | **채택** |

OpenAlex 는 공개 API(키 · 로그인 없음). orx 는 쓰지 않는다(정책상 봇 경로 금지 그대로). 이메일 등 사용자 정보는 보내지 않는다.

## 1. 바꾸는 것 — `RAG_EXTERNAL_SEARCH` (기본 `0`)

`1` 이면 논문 질문(B 경로) 중 **아래 경우에만** OpenAlex 를 부른다:
- (a) 정답 유무 판정이 **'없음'** (판정 대상 질문), 또는
- (b) **목록 모드** 질문(동향 · 목록 — 판정을 건너뛰는 유형이라 DB 에 빠진 논문을 알릴 길이 없다).

동작:
- 검색어 = 이미 만든 영어 검색어(`rag_query`). `per-page 8`, 응답 시간 상한 **6s**, 실패하면 아무것도 안 붙인다.
- 답변 생성(LLM)과 **동시에** 부른다(스레드) — 답변이 끝난 뒤 남은 시간만 기다린다.
- 결과에서 **이미 컨텍스트에 있는 논문 · 2017년 이전 · 제목 없는 것**을 빼고 앞에서 **최대 4편**.
- 답 끝에 덧붙인다: "📎 DB 밖에서 찾은 관련 논문 (OpenAlex 검색 · 내용은 요약하지 않음)" + 제목 · 연도 · 링크(arXiv 가 있으면 arxiv.org/abs, 없으면 DOI/OpenAlex 링크). **본문 내용은 쓰지 않는다** — 읽지 않은 논문을 요약하면 날조가 되므로.
- 나온 arXiv ID 는 `.bridge/external_candidates.jsonl` 에 남긴다(나중 수집 후보 — 이 라운드에서 자동 수집은 하지 않는다).

## 2. 측정 (맥미니)

- 질문: corpus_seed_1020 의 held-out 30 + 직무 질문 34 = 64. 지금 운영 상태(수집 후)의 검색어 · 컨텍스트(`cs1_H` · `cs1_D` 저장분)를 쓴다.
- 질문마다 (1) 트리거 여부 = 판정(운영 판정 함수, 지금 운영 설정)이 '없음'이거나 목록 모드인지, (2) OpenAlex 결과(위 규칙 그대로 최대 4편)와 응답 시간.
- **관련성 판정**: 덧붙일 외부 논문(제목 + OpenAlex 초록)을 Claude 가 corpus_seed 와 같은 0 · 1 · 2 척도로 판정. 비교 기준으로 같은 질문의 DB 컨텍스트 판정(이미 있음)을 쓴다.
- 운영 경로 확인: 트리거된 질문 몇 개를 실제 답변까지 돌려 덧붙임 형식 · 추가 지연을 본다.

## 3. 판정 (측정 전 고정)

| 지표 | 기준 |
|---|---|
| **주:** 트리거된 질문 중 외부 결과에 '2' 논문이 1편 이상 있는 비율 | ≥ 50% |
| 부: 트리거된 질문 중 DB 컨텍스트에는 '2' 가 없었는데 외부 결과에는 있는 질문 수 | 보고 |
| 보호: 덧붙인 외부 논문 중 '0'(무관) 비율 | ≤ 30% |
| 보호: OpenAlex 실패(시간 초과 · 오류) 비율 | ≤ 10% |
| 보호: 답변까지 잰 질문의 추가 지연(답변 끝난 뒤 더 기다린 시간) 중앙 | ≤ 2s |
| 보고: 트리거 비율(64 중), 외부 결과 중 arXiv ID 있는 비율, 이미 DB 에 있던 비율 | |

채택이면 **사용자 승인 후** 운영 `.env` `RAG_EXTERNAL_SEARCH=1` + 봇 재시작.

예상: 트리거 25~40/64, 그중 '2' 있는 질문 60~75%, 무관 15~25%, 실패 0~5%, 추가 지연 0~1s.
