## 읽을 점
- **① 은 거의 전부 힌트 답에서 난다(27/37 = 73%).** 모델이 힌트 형식의 `(관련 연구)` 표시를 한 번도 안 썼고(0/37), 최대 2 개 제한도 12 답이 넘겼다. 그래서 가까운 문서를 정답처럼 나열한 뒤 결론만 '없음' 이 된다. 판정이 맞는 '없음' 이어도 답이 모순으로 보인다 — 판정 정확도와 별개의 **답 틀 문제**다.
- **⑤ 도 대부분 힌트 답(13/37 = 35% vs 비힌트 1/83).** 정답이 없을 때 "가장 가까운 문서" 를 억지로 소개하면서 무관 문서가 들어간다(BGE M3 질문에 읽기 목록 논문 · RETRO 질문에 EHR 논문 · 꿀벌에 작물 추천 등).
- 비힌트 답은 '없음' 을 스스로 쓸 때 대부분 문서별로 왜 안 맞는지 설명한다(설명형 6) — 이 꼴이 후보 B(판정에 덜 기대는 답 틀, judge_v2_1113 §8) 가 노리는 형태다.
- ② · ③ 은 드물다(각 2). ③ 의 남은 2 는 한 번만 나온 외래어 음차.
- ④ 의 비힌트 위반 2 는 '두 편' 요청에 세 편. 힌트 형식의 '최대 2 개' 는 개수 요청과 충돌한다.

- `count_notice` 가 바뀐 것은 기간 밖일 때뿐이다: 예전에는 맨 앞에 `※ 요청한 기간(…)에 나온 논문은 찾지 못해, 기간 밖 논문으로 답했습니다.` 한 줄을 붙였고, 이제는 그 대신 서론 첫 문장을 고정한다. 개수 고지(`※ 요청한 N편 중 M편만 찾았습니다.`)는 문구 · 조건 그대로. 돌려주는 기록용 문자열에 `서론 기간 밖 고정` 이 붙는다.
- 기간 밖 11 답을 사람이 보며 고친 것 3 가지(커밋 전): ① 인용 ID 의 점(`[2512.24044v1]`)에서 문장을 잘라 결론의 연도 문장이 안 빠지던 버그 → 문장 끝을 "뒤에 공백이 오는 . ! ?" 로 · ② 서론에서 연도 문장만 빼면 남은 "이러한 흐름은 …" 이 빠진 문장을 가리킴 → 한 문장이라도 빼면 서론의 모델 문장은 모두 버림 · ③ 이미 고친 답에 다시 불리면 문장이 겹침 → 고정 문장이 있으면 그대로. 결론에서 앞 문장을 뺀 뒤 "또한" 으로 시작하면 이음말을 뗀다.
