# 주제형 질문의 검색 품질 — 눈가림 관련성 판정 (사전 등록, 2026-10-24)

> 측정 **전에** 쓴다. 출발점: lang_query_1023 §6 — 조건 세트(aspect_split_1022)의 정답 목록은 제목 검색으로 고른 일부라 다른 관련 논문을 가져와도 0으로 센다. 주제형 질문의 검색 품질을 정답 목록 없이 재는 기준이 필요하다. corpus_seed_1020 과 같은 3단계 눈가림 판정을 쓴다.

## 1. 대상

- 주제형 37문항: real40 T01–T08 · R01–R06(14), real2 T01–T08(8), 조건 세트 M01–M12(12), corpus_seed_1023 R01 · R03 · R04(3; R02 는 M01 과 같은 질문이라 뺀다).
- 컨텍스트(답변 모델에 간 번호표 논문, `doc_ids`): `lq_ko_*`(10-23 운영 그대로, 검색만). 조건 세트 · R 3문항은 `lq_ko_nofilter_*`(관련 문서 거르기 끔) · `lq_ko_nolr_*`(light rerank 끔)도.

## 2. 판정

(질문, 논문) 쌍을 조건과 무관하게 한 번씩만 모아(같은 질문 · 같은 논문은 한 쌍) 무작위로 섞고, Claude 가 **조건을 모른 채** 제목 + 초록 요지(`brief_findings`, 600자)로 매긴다 — **2** 질문에 직접 답하는 연구 · **1** 같은 주제지만 질문의 조건 · 대상과 다름 · **0** 무관. 판정 파일 `judged.tsv` 를 남긴 뒤 조건을 붙인다.

## 3. 지표 (측정 전 고정)

| 지표 | 쓰임 |
|---|---|
| 문항당 '2' 논문 수 · '2' 가 1편 이상인 문항 비율 · 컨텍스트 중 '0' 비율 | **운영 기준선**(37문항) |
| 조건 세트 + R 3 (15문항): 운영 대 거르기 끔 대 light rerank 끔 — 문항당 '2' 수 부호 검정, '0' 비율 | lang_query_1023 §6 의 "총량 그대로" 결론을 정답 목록 없이 다시 확인(보고) |

채택 판정이 아니라 **기준선 측정**이다. 이후 주제형 검색 라운드는 이 판정 방식을 주 지표로 쓴다.
