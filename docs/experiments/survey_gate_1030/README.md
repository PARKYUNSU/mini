# 조사형 질문("…연구 찾아줘 · 조사해줘")을 목록 모드로 (사전 등록, 2026-10-30)

> 측정 **전에** 쓴다. 출발점: [`query_example_1029/`](../query_example_1029/) §6 · §7 — 실사용 job 134 · 135 · 136("…연구에 대해서 조사해줘")이 세 번 다 "찾을 수 없음". 판정은 H3D(문서 중복 제거) 하나만 남긴 컨텍스트에서도 '없음'이었다. 운영 판정 프롬프트(v1)는 "사용자는 **특정한 연구 하나**를 찾고 있다"를 가정하는데, 이 질문은 분야 조사다. 목록 게이트(`논문들|연구들|동향|정리해|트렌드|N개 찾|목록`)에 "조사해줘 · 연구 찾아줘"가 없어 판정을 받고 목록 모드(10편 · 판정 없음)도 안 탄다.
> 실사용 136 job 중 이 꼴(게이트 밖) 7: 119 · 127 · 132 · 133 · 134 · 135 · 136 — 그중 '없음' 답 3(134 · 135 · 136).

## 1. 바꾸는 것 — `RAG_SURVEY_GATE=1` (기본 0)

`core/llm/presence_judge.gate_types` — 플래그가 켜져 있고 질문이 `조사\s*해|연구\S*\s*(좀\s*)?(찾아|알아봐)` 에 걸리면 `list` 유형을 붙인다. 그러면 기존 운영 경로 그대로:
- 목록 모드(`RAG_LIST_MODE=1`): 10편 다시 검색 · 짧은 블록 · 번호 칸 템플릿(`RAG_LIST_SLOTS`) · 결과 문장(`RAG_LIST_FINDINGS`).
- 정답 유무 판정을 건너뛴다(`RAG_PRESENCE_GATE=1`).
- 외부 검색(목록 질문에 붙음, `RAG_EXTERNAL_SEARCH`).

넣지 않은 것: "서베이"(162 C1 은 서베이 논문 **한 편**을 찾는 질문) · "연구 있어?"(예/아니오 + 특정 연구 찾기가 섞임 — 162 에 12문항). 단위 테스트 `tests/unit/test_presence_gate.py::test_survey_gate_flag`.
