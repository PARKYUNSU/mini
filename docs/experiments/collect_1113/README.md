## 1. 바꾸는 것 — 코퍼스에 논문 추가 (코드 · 설정 변경 없음)
- 후보 규칙(손으로 고르지 않음): 운영 봇이 DB 밖(OpenAlex) 목록으로 보여 주고 기록한 `.bridge/external_candidates.jsonl`(11-13 22시 기준 2,028 줄 · 고유 1,219 편) 중 **DB 에 없고 서로 다른 질문 2 개 이상에서 나온 논문 93 편** + 고정 2 편(오늘 점검에서 원논문이 없던 RankGPT 2304.09542 · AWQ 2306.00978) = **95 편** → `candidates.yaml`.
