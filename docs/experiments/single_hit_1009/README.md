# 짧은 요약·설명 요청의 Top-1 컨텍스트 규칙 끄기 (사전 등록)

- 시작일: 2026-10-09
- 선행: [`../topic_gate_1009/README.md`](../topic_gate_1009/README.md) §9.1 — 게이트 반영 후 끝단 0.667, 검색 단계 대비 남은 손실 47 중 **21 이 컨텍스트 1편**.

## 1. 조치

`_prefer_single_hit_rag_context` 의 "44자 이하 + 요약/알려줘/설명해 → Top-1" 규칙을 끈다 (`RAG_SINGLE_HIT_SHORT_QUERY=1` 이면 되살아남 — 비교용). 막연한 요청("아무거나 하나")·심층 모드의 Top-1 은 그대로다. 이 규칙이 켜지면 검색도 `top_k=3` 으로 줄고 컨텍스트는 1편만 남는다. 끄면 `top_k=15` · 상위 5편.

`gate2_r1` 에서 RAG 경로 141문항 중 57문항이 1편 컨텍스트였고(35 적중), 그중 53문항이 이 규칙 때문이다.

## 2. 측정

1. **주 (컨텍스트)**: `eval_e2e_ko.py --label single_off` — 162문항, 답변 LLM 스텁. 기준선은 `gate2_r1`(규칙 켬, 같은 코드의 나머지).
2. **안전장치 (실제 답변)**: [`subset_ids.txt`](subset_ids.txt) 의 57문항 (`gate2_r1` 에서 1편 컨텍스트였던 것) 을 `--answer` 로 두 번 —
   `ans_old` (`RAG_SINGLE_HIT_SHORT_QUERY=1`) · `ans_new` (기본). 지표: 답변이 정답 논문 ID 를 인용(`answer_ok`), 첫 인용이 정답(`answer_first_ok`).

## 3. 판정 (결과 전 고정)

- 주: `single_off` vs `gate2_r1` 짝지은 McNemar, 끈 쪽이 p<0.05 로 우세.
- 안전장치: 57문항에서 `answer_ok` 가 `ans_new` 쪽만 맞힌 수 ≥ `ans_old` 쪽만 맞힌 수 (나빠지지 않음). `answer_first_ok` 는 보고만 한다 — 여러 편이면 첫 인용이 다른 논문일 수 있는 것은 설계상 예상된 비용이다.
- 둘 다 통과하면 반영. 하나라도 못 미치면 반영하지 않는다.

## 4. 예상

- 주: 0.667 → **0.75 이상**. 단일 컨텍스트 손실 21 중 다수가 살아난다. 다만 `top_k` 3 → 15 로 바뀌어 다른 문항의 순위도 흔들릴 수 있다.
- 안전장치: `answer_ok` 는 오른다(정답이 컨텍스트에 더 자주 들어가므로). `answer_first_ok` 는 떨어질 수 있다.
