# R8 확인 라운드 — 열린 요청은 판정 건너뛰기 (2026-11-03, 사전 등록)

## 0. 왜

- 1회차(`open_gate_1103`)는 방향이 처리 쪽이었다: 6:1 · 동점 2, 거짓 '없음' 6 → 0, 응답 −20s.
- 하지만 바뀐 문항이 9뿐이라 p 0.125 로 주 지표에 못 미쳤다.
- 사용자 결정(11-03)으로 새 held-out 질문만으로 다시 잰다. 1회차 결과와 합쳐 판정하지 않는다(합친 수는 보고만).

## 1. 바꾸는 것 — 1회차와 같음

- `RAG_OPEN_GATE=1`(기본 0)이다. `_GATE_OPEN` 정규식과 `should_judge` 는 dded247 그대로이고, 1회차 결과를 보고 바꾸지 않았다.
- 대조는 운영 `.env` 그대로, 처리는 `RAG_OPEN_GATE=1` 이다.

## 2. 문항 (held-out, 판정 전용)

- 새 held-out 120(`heldout_open2.tsv`, OB_001–OB_120): 열린 요청 꼴이다(추천 · 볼만한 · 읽을 · 읽어야 할 · 재밌는 · 괜찮은 · 좋은 논문 · N편 · 아무 논문 · 뽑아줘 · 골라줘 · 최신 논문).
  - 주제 60 × 말투 2 다. 검색 · 에이전트 · 평가 · 정렬 · 추론 · 학습 · 다국어 · 멀티모달 · 응용(의료 · 법률 · 금융 · 보안 · 교육 · 과학)에 걸친다.
  - DB 를 보지 않고 썼다.
  - 기존 질문(서로 다른 1,052)과 세트 안 서로 간 SequenceMatcher 가 모두 0.75 미만이다. 넘은 8 은 고쳐 썼다.
  - 120 모두 대조에서는 판정이 돌고 처리 규칙에는 걸린다. 목록 · 수치 · 비교 게이트에는 하나도 안 걸린다.
- 1회차 새 질문 50 과 판정에 쓴 기존 held-out 6 은 쓰지 않는다.

## 3. 측정 (1회차 §4 와 같은 절차)

- 1단계: 대조로 `eval_e2e_ko.py --save-context`(답 생성 없음) 120을 돌린다. 판정 뒤 단계인 외부 검색 · 결론 다시 쓰기는 끈다. 결과는 `ogb_s1`.
- 바뀌는 문항 = 대조 판정이 '없음'인 문항이다(120 모두 규칙에 걸림). `pick_s2.py` 가 고른다.
- 2단계: 바뀌는 문항만 대조 `ogb0_s2`(`RAG_OPEN_GATE=0`) · 처리 `ogb1_s2`(`=1`)로 `--answer --save-context` 를 돌린다.
- 판정 묶음에는 두 조건의 `answer_input` 이 다른 문항만 넣는다(protocol §2.5). 답 끝 📎 외부 목록은 잘라 낸다. A/B 는 시드 11032 로 섞는다. 열쇠는 라벨을 다 쓴 뒤 연다. 판정자는 Claude 1명이다(`pool.py` · `blk.py`).

## 4. 판정 기준 — 측정 전 고정 (1회차 §5 와 같음)

- 고르는 순서: (1) 사실 오류가 확연히 적은 쪽. 차이 1 이라도 결과의 뜻을 바꾸면 확연하다고 본다. (2) 질문에 맞게 답한 쪽. 주제에 맞는 논문을 소개하면 맞고, 정말 없을 때는 맞는 '없음'이 맞다. (3) 인용 관련성. (4) 동점.
- 답마다 무관 인용 '0' · 거짓 '없음' · 거짓 '있음'을 센다.

| 지표 | 기준 |
|---|---|
| **주:** 판정한 문항 승패 | 처리 승 > 대조 승, 부호 검정(동점 제외) 양측 p < 0.05 — 이번 라운드만으로 |
| 보호 1: 거짓 '있음' 합 | 처리 ≤ 대조 + 2 |
| 보호 2: 무관 인용 '0' 합 | 처리 ≤ 대조 × 1.5 (대조가 0이면 ≤ 2) |
| 보호 3: 응답 시간 중앙(판정 문항) | 처리 ≤ 대조 + 20s |
| 보고: 거짓 '없음' · 인용 편수 · 1회차와 합친 승패 · 경로 분포 | |

## 5. 문항 수 (protocol §2.5)

- 1회차 1단계에서 열린 요청 판정 '없음'은 18% 였고, 라우터가 RAG 밖으로 보낸 문항이 10% 였다.
  - 그대로면 바뀌는 문항은 120 × 0.9 × 0.18 ≈ 19 다.
  - 동점 ~20% 를 빼면 판정할 문항은 ~15 다.
- 1회차 효과 6:1(86%)이면 동점을 뺀 15 에서 기대 13:2 → p ≈ 0.007 이다. 3:1 이면 17 이 필요해 빠듯하다.
