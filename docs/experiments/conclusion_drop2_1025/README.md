> 측정 **전에** 쓴다. 출발점: conclusion_drop_1025 — 다시 쓰기 탈락 경로에는 지울 문장이 없었고(0 / 11), 묶기 · 일반화 오류는 **검사를 통과한 v2 결론** 안에 있었다. 사후 탐색(같은 판정 라벨, 사전 등록 아님): 통과한 v2 결론 33 개에 같은 규칙 → 걸린 답 7, E+X 가 줄어든 답 6, 지운 8 문장 = X 6 · E 1 · O 1. 이번에는 **새 질문 · 새 답**으로 다시 잰다.

## 1. 바꾸는 것 — `RAG_CONCLUSION_DROP_BUNDLED=1` 의 범위를 넓힘 (기본 0)

- conclusion_drop_1025 의 `drop_bundled` 를 결론 다시 쓰기가 **바꾼 결론("바꿈")에도** 적용한다(탈락 경로는 그대로). 규칙은 같다: 서로 다른 arXiv ID 를 둘 이상 인용한 문장 · `_OVERGEN` 일반화 문장을 지우고, 인용 문장이 안 남으면 그대로 둔다.
- 플래그는 운영에서 켠 적이 없으므로 의미만 넓힌다. 상태 문자열 `바꿈 · 묶기 N 지움`.

- **새 질문 30** (`questions.tsv`, 이 문서와 함께 측정 전 고정): 주제형 정리 D01–D20 · 방식 비교 D21–D30. 이전 평가 세트와 겹치지 않게 새로 쓴 문장(주제는 코퍼스 분야).

| 지표 | 기준 |
