## 1. 바꾸는 것
- `RAG_FILTER_NONE_KEEP=N`(기본 0 = 지금처럼 다 남김): `filter_relevant` 가 '없음' 이면 검색 순위 상위 N 편 + 이름 보호 문서만 남긴다. 상태 `없음→N`.
- 후보 N=1 하나만 잰다.

## 2. 측정 — held-out (판정 전용)
- 세트: `cl1_heldout`(11-14 운영 상태, 검색만) 120 문항 중 거르기 상태가 '없음' 인 **10 문항**. 지금은 15 편이 그대로 남아 상위 5 가 답 컨텍스트가 된다 → N=1 이면 1 위만 남는다. 빠지는 문서 = 각 문항의 2–5 위.
- 라벨: 그 10 문항의 상위 5 문서(50 쌍)를 질문 · 제목 · 초록만 보고 관련 / 무관(Claude 1 명, 문서 순위 · 빠질지 여부 가림, 섞음).
