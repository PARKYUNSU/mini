# 질문 언어가 검색에 주는 영향 — 한국어 / 평이한 영어 / 분야 용어 영어 (사전 등록, 2026-10-23)

> 측정 **전에** 쓴다. 출발점: 사용자 질문 — "번역 때문에 오류가 생기는 건가?" 검색 쪽 번역(한국어 질문 → 9B 가 만드는 영어 검색어)이 원인인지, 분야 용어(예: "lost in the middle")를 모르는 것이 원인인지 가른다. 답 생성 쪽 번역(영어 초록 → 한국어 답)은 이 라운드 대상이 아니다.

## 1. 조건 (코드 · 설정 변경 없음, 질문 문장만 바꿈)

- `ko`: 한국어 원문 질문(오늘 다시 잼).
- `en_plain`: 원문을 뜻 그대로 옮긴 영어(Claude 번역). 원문에 있는 이름(DDC · JetSpec …)은 유지, 원문에 없는 분야 용어는 넣지 않는다.
- `en_term`: 주제형 38문항(real40 T · R, real2 T, M12, R01–R04)만 연구자들이 쓰는 표준 용어를 넣은 영어. 나머지(특정 논문 N · C)는 `en_plain` 과 같다. 논문 제목은 넣지 않으려 했으나 M01 · R01 의 "lost in the middle" 처럼 **분야 용어가 곧 논문 제목인 경우**가 있다(한계).
- 파일: `en_plain_*.tsv` · `en_term_*.tsv`. 질문 문장 외에는 운영 경로 그대로(라우터 → 검색어 추출 → 검색 → 답변 노드 컨텍스트, 답 생성 없음, `--save-context`).

## 2. 세트 · 지표

- real40 · real2 74문항: 검색 ok(정답 논문이 컨텍스트에).
- 조건 세트 12문항 × 조건 24(aspect_split_1022): 컨텍스트 조건 커버.
- 주제형 R01–R04(corpus_seed_1023): 컨텍스트 gold 수.
- 보고: 경로(RAG 를 탔는지 — 영어 질문이 다른 경로로 갈 수 있다), 검색어(`rag_queries[0]`) 예.

## 5. 결과 (2026-10-24) — **번역은 원인이 아니다. 한국어가 가장 좋다.**

| 지표 | `ko` | `en_plain` | `en_term` |
|---|---|---|---|
| real 74 검색 ok | **64** | 56 (얻음 2 : 잃음 10, **p 0.039 — 영어가 유의하게 나쁨**) | 53 (평이 대비 3 : 6) |
| 경로가 RAG 가 아님 | 2 | **6** (planner/C) | 6 |
| 조건 커버 (24) | 10 | 8 | **11** (평이 대비 +3, 기준 +4 미달) |
| R01–R04 컨텍스트 gold | 3 · 1 · 0 · 0 | 1 · 0 · 0 · 0 | 3 · 1 · 0 · 0 |

**영어에서 잃은 10문항** — 6개는 **라우팅**(영어 질문이 계획 경로 planner/C 로 감: N01 · N14 · C05 · real2 N02 · C02 …), 나머지는 **비교 질문**(C02 · C03 · C07 · C08 · C10): 비교 분리 검색 게이트가 한국어 표지("차이 · 비교 · 달라")로 걸려서 영어 질문에서는 돌지 않는다. 즉 영어가 나쁜 것은 번역이 아니라 **파이프라인이 한국어에 맞춰져 있어서**다.

**판정(§3)** — 번역이 원인: 아님(평이 영어가 오히려 나쁨). 분야 용어가 원인: 기준 미달(조건 커버 +3, 주제형 T · R 1 : 2). 질문 언어 · 용어를 바꿔도 주제형 검색(조건 커버 8~11/24)은 크게 안 바뀐다 → **다른 원인**.

**다른 원인 단서** — paper_ce_1023 의 운영 논문 점수 순위(디버그)에서 조건 세트 정답이 상위 5 안인 조건은 **14/24**, 상위 10 안은 16/24 인데 실제 운영 컨텍스트 커버는 **10/24** 다. 논문 점수 **이후 단계**(목록 모드 재검색 · light rerank · 관련 문서 거르기 · 칸 자르기)에서 4개 이상이 빠진다. final_select_1023 의 1번 갈래("점수는 상위인데 운영에서 빠짐")와 같은 곳.

**읽은 것** — 어느 한 단계도 "빠짐"의 원인이 아니다. 거르기를 끄면 1개 늘고, light rerank 를 끄면 맞는 조건이 **바뀔 뿐 총량은 같다**(얻음 4 : 잃음 3, R01–R04 는 오히려 전부 잃음). 주제형 질문에서는 신호들이 약하고 엇비슷해서 어떤 단계를 바꿔도 순위가 뒤섞이는 상태다. 또한 조건 세트 정답 목록은 제목 검색으로 고른 일부라 **다른 관련 논문을 가져와도 0으로 센다** — 이 세트로는 주제형 검색의 실제 품질을 재기 어렵다.
