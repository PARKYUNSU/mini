## 3. 읽은 것

1. **운영 하이브리드가 BM25 단독보다 낫지 않다.** 8:8 로 정확히 맞바꾼다. 벡터를 섞어 얻는 문항만큼 잃는다.
2. **BM25 가 1위로 찾은 것을 production 이 놓친다.** production 미스 13개 중 6개는 BM25 순위가 1~3위였다 (`A035`·`A063`·`A112`·`C1_06`·`C1_07`·`C2_03`). `C2_03`(GPT-3)·`C1_06` 은 **벡터와 BM25 가 둘 다 상위**인데 production 이 10위 밖으로 밀었다 → 융합·논문 집계·재정렬 단계의 문제이고 임베딩 기하와 무관하다.
3. **벡터 단독이 가장 약하다** (bm25 대비 5:22). 임베더 교체의 여지가 실재한다.
4. **C1(survey)에서 벡터가 특히 약하다** — A 0.873 → C1 0.708, production 도 0.941 → 0.792. 넓은 질의에 넓은 논문을 못 올리는 일반성 불일치 신호다 (§5 E4). 단 C1 정답이 제목 기준 하한이라(§2.2-2) 일부는 정답 누락일 수 있다 → 상위 5편 수작업 확인 전에는 확정하지 않는다.

## 4. 해석의 한계

- **A 는 BM25 에 유리할 수 있다.** 제목 단어는 피했지만(Jaccard ≤0.55) 질의를 초록을 읽고 썼으므로 **초록 어휘**와 겹친다. A 에서의 bm25 우위는 그만큼 할인해야 한다. 실제 사용자 질의(한국어 → LLM 키워드)로 같은 비교를 하기 전까지는 "BM25 가 벡터보다 낫다" 를 일반화하지 않는다.
- B 가 세 갈래 모두에서 낮은 것(0.36~0.56)은 그 25문항의 정답 지정 자체를 의심하게 한다 (예: "vision transformer image classification" 의 정답이 ViT 원 논문이 아니라 2412.16188 survey).
