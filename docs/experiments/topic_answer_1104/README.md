## 1. 바꾸는 것 (`RAG_TOPIC_ANSWER=1`, 기본 `0`)

여러 주제 후보 질문(`topic_answer_items` 가 항목을 읽어 낸 질문)만 — 그 밖의 질문은 코드 경로가 같다:

1. **항목별 판정(`judge_items`)** 이 정답 유무 판정을 대신한다. 답변과 같은 앞부분에 "문서마다 그 문서가 다루는 항목" 을 묻는다. 실패 · 형식 밖이면 기존 판정으로 간다.
2. **모든 항목에 문서가 없으면** 기존 '없음' 경로(전체 없음 문구)를 쓴다. 그때만 그 문구가 맞다.
3. **일부만 없으면** 답 프롬프트에 항목별 문서 표를 넣고, 결론 다시 쓰기에 "문서에 없는 항목은 다루지 마라" 를 넘기고, **코드가 답 맨 앞에 `※ 제공된 문서에서 찾지 못한 항목: …` 을 붙인다**(결론 다시 쓰기가 못 지우게).
4. 외부 검색은 항목 판정이 돈 질문에도 돈다(판정 '없음' 조건을 대신).
