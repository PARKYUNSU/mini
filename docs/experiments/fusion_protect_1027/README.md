# 벡터 · BM25 둘 다 상위인 논문 지키기 (사전 등록, 2026-10-27)

> 측정 **전에** 쓴다. 출발점: user_suite_1027 검색 놓침 진단 원인 2 — U1-4(샘플링 일관성 환각 탐지)의 정답 FactSelfCheck · Finch-Zk 가 벡터 논문 순위 2 · 3, BM25 1 · 2 인데 최종 논문 점수(상위 청크 합 · 다중 근거 · 제목 유사도 · light rerank) 뒤 8 · 12 위로 밀려 답(상위 5)에 못 들어갔다. paper_ce_1023 의 "청크 하나짜리 정답이 밀린다"와 같은 계열로 본다.

## 1. 바꾸는 것 — `RAG_FUSION_PROTECT=1` (기본 0), `RAG_FUSION_PROTECT_K=3`

`core/rag/agent_chroma_rag.py` `_fusion_protect_pids` · `_paper_max_one_chunk_per_paper(protect_pids=)`, 테스트 `tests/unit/test_fusion_protect.py`.

- 후보 풀에서 벡터 논문 순위(논문별 최소 거리)와 BM25 논문 순위(`bm25_pid_scores`)가 **둘 다 K(=3) 안**인 논문을 고른다.
- 최종 논문 순위가 끝난 뒤 그 논문이 상위 top_k(목록 10 · 그 밖 5) 밖이면, 상위 top_k 의 **끝자리**를 그 논문으로 바꾼다(앞 순위는 그대로). 이미 안에 있으면 아무것도 안 함.
- K 는 진단 2 건(2 · 1, 3 · 2)에 맞춰 측정 전 3 으로 고정.

## 2. 방법 (맥미니, 검색만 — `--answer` 없음, 운영 설정 그대로)

대조 `fp0_*` · 처리 `fp1_*`: 정답 있는 세트 162 · real40 · real2 + held-out 30(H) · 직무 34(D) · 사용자 34(U).

- **관련성 판정(주 지표):** H · D · U 의 두 조건 컨텍스트 논문 중 아직 판정 안 된 쌍만 섞어 조건을 모른 채 0 · 1 · 2 판정(2 = 질문을 직접 다룸). 이미 판정된 쌍(corpus_seed `.cron/cs/judged_*` · query_norag_1027 `judged.txt`)은 재사용.

## 3. 판정 (측정 전 고정)

| 지표 | 기준 |
|---|---|
| **주:** H + D + U (98) — 질문별 컨텍스트 '2' 논문 수 | 처리 > 대조, 부호 검정(동점 제외) 양측 p < 0.05 |
| 보호: 정답 있는 세트 검색 ok (162 + real40 + real2) | 처리가 대조보다 3 이상 낮지 않음 |
| 보호: 바뀐 자리 판정 | 들어온 논문 '2' 수 ≥ 빠진 논문 '2' 수 |
| 보고: 보호가 작동한 문항 수 · U1-4 정답이 컨텍스트에 들었는지 | |

보호 미달이면 주 지표 판정 없이 기각. 채택이면 사용자 승인 후 운영 `.env` 반영 + 봇 재시작.

예상: 보호가 작동하는 문항은 많지 않다(대부분 둘 다 상위인 논문은 이미 상위 5 안). 작동 문항이 적으면 부호 검정 표본이 작아 유의가 어렵다 — 그때는 바뀐 자리 판정(들어온 · 빠진 논문)을 주로 해석하되 채택 기준은 위 표 그대로.
