## 2. 단계별 점검 (지시서 §3)

### 2.1 수집 — 대표 논문이 부족하다

- **연도:** 2023년 이전이 2.4% 다. 매일 수집이 최신 cs.AI 만 받기 때문이다.
- **잘 알려진 RAG 논문 16편 중 7편만 있다.** 있음: RAG(2005.11401) · DPR · Self-RAG · CRAG · Lost in the Middle · RGB(2309.01431) · Power of Noise(2401.14887). 없음: REALM · RETRO · Atlas · HyDE · FLARE · RAGTruth · ALCE(인용 생성) · **방해 문서 고전 두 편**(2302.00093 · 2310.01558).
- **주제별 인용 상위 5편(OpenAlex, arXiv 판이 있는 것):** 10주제 50편 중 **17편(34%)**. 재순위 0/5 · 방해 문서 강건성 0/5 · 긴 컨텍스트 1/5 · LLM 판정자 1/5. 검색어가 넓어 주제와 먼 논문도 섞였으니 비율은 대략값이다.
- 버전 중복은 0 이다(논문당 한 버전만 받는다).

### 2.2 파싱 · 청킹 — 크게 나쁘지 않다

- **무작위 청크 20개(seed 1110, id 로 조회):** 정상 14 · 수식 잔해 2 · 그림 설명 2 · 저자 목록 1 · 짧은 조각 1. 참고문헌만 있는 청크 0, 200자 미만 2, 너무 긴 청크 0(500자 상한).
- **메타:** 20개 모두 arXiv ID · 제목 · 발행일 · 초록이 붙어 있다. 논문 8,010편 모두 제목 · 초록 · 저자가 있다(저자는 청크 메타에는 없음).
- 초록은 청크와 따로 메타에 있고 답 컨텍스트에 논문별로 붙는다(`RAG_CONTEXT_ABSTRACT`). 본문 속 깨진 소수점 56% 는 11-07에 읽을 때 고치게 했다.

### 2.3 검색

- **한국어 질문 → 영어 검색:** 임베딩이 영어 전용이라 보조 LLM 이 영어 검색어를 만든다. 질문에 든 영어 키워드 167개 중 **139개(83%)** 가 검색어에 그대로 들어갔다(dev 답 249, 키워드가 있는 질문 83). 빠진 것은 대부분 표기 차이(`warm-start` → `warm start`)이고, 실제로 바뀐 예는 `LVLM` → `lvm`, `sycophancy` → `sycophany` 다. **같은 질문을 한국어와 영어로 넣은 비교는 아직 하지 않았다.**
- **고유 이름:** 이름 찾기(`RAG_NAME_LOOKUP`) 뒤 held-out 이름 정답 2/4 → 4/4(11-01).
- **여러 요소 질문:** 3주제 질문 40개(HU40)의 121주제 중 검색이 덮는 주제는 79(65%)다. 거르기가 완벽해도 93 이다(`topic_filter_1104`). 한 논문의 독점은 논문당 한 블록으로 막았다.
- **Recall:** real40 검색 정답 32/34(11-08).

### 2.4 생성

- **근거 충실도:** 결론 주장의 정확도 51%(본론 84%), 사실 오류 16% · 과장 8%(`answer_judge_1024`, 결론 다시 쓰기 전). 숫자 단위 오류 0(`unit_check_1106`), 근거 없는 숫자 458개 중 4개(`num_absent_1107`).
- **인용 정확도:** 컨텍스트 밖 인용 0/40(주간 점검). 인용 ID 는 이번 컨텍스트에서만 나온다(`citation_fix`).
- **요소 커버리지:** 문서가 없는 주제 42개 중 '없다'고 밝힘 7 · 다른 내용에 묻힘 16 · 말하지 않음 10 · 지어냄 7(`answer_gap_1104`).
- **'모름' 처리:** 판정 '없음' 22건 중 11건이 거짓이었다(`judge_none_1103`). 정답이 없을 때 일관되게 알린 비율은 12/21(`presence_integration_1012`).

### 2.5 파인튜닝

- v9 는 같은 컨텍스트에서 base 보다 내용 정확도가 낮았다(49:2, 10-10). 그래서 문서 근거 데이터로 다시 학습했다.
- v12 vs base 는 ok 124:121(p 0.66) · 지어냄 5:20(p 0.004, v12 가 적음)이었다. v13 답은 120B 답 대비 ok 96% · correct 78% 이고, 차이는 대부분 '덜 자세함'이었다(`upper_bound_1013`).
- **지금 운영(v13 + 지금 파이프라인) vs 같은 베이스 원본(qwen3.5:9b) 비교는 없다.** 새 맥미니 모델 비교([`newmac_1105`](../newmac_1105/README.md) §6)에 base 팔을 더해 잰다.
