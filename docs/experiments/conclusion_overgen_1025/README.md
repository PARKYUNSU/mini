## 1. 바꾸는 것 — `RAG_CONCLUSION_DROP_BUNDLED=overgen` (기본 0)

- 결론 다시 쓰기 뒤(바꿈 · 탈락 경로 모두) 결론에서 `_OVERGEN`(모든 연구/논문/문서/방법 · 공통(된|으로|적|점) · 모두 … 공유/같/일치/보여) 에 걸리는 문장만 지운다. 묶음 규칙은 쓰지 않는다. 인용 문장이 안 남으면 그대로.
- 값 `1` 은 conclusion_drop2_1025 의 두 규칙 모두(기각, 운영에서 쓰지 않음).

## 2. 방법

- **새 질문 40** (`questions.tsv`, 측정 전 고정): 주제형 정리 E01–E30 · 비교 E31–E40. 이전 세트(pb1 · cd2 등)와 다른 주제 · 문장. 질문을 30 → 40 으로 늘린 이유: 이전 라운드에서 일반화 규칙이 걸린 답이 7/27 이라 유의(≥ 6)를 넘기려면 대상이 더 필요.
- 맥미니에서 운영 설정(`.env` 그대로, 플래그 0)으로 답 생성: `scripts/eval_e2e_ko.py --answer --save-context --questions …/questions.tsv --gold …/gold.jsonl --label cov_new`.
