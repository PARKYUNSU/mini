# 결론 일반화 문장만 지우기 (사전 등록, 2026-10-25)

> 측정 **전에** 쓴다. 출발점: conclusion_drop2_1025 — 통과한 v2 결론에서 묶음 · 일반화 문장을 지우니 E+X 11:0 이었지만, **묶음 규칙**(한 문장에 서로 다른 논문 2편 이상 인용)은 지운 23 문장 중 O 16 이라 기각. **일반화 규칙**(`_OVERGEN`)은 지운 7 문장이 전부 X(사후 분리 · 같은 데이터). 이번에는 일반화 규칙만, **새 질문 · 새 답**으로 잰다.

## 1. 바꾸는 것 — `RAG_CONCLUSION_DROP_BUNDLED=overgen` (기본 0)

- 결론 다시 쓰기 뒤(바꿈 · 탈락 경로 모두) 결론에서 `_OVERGEN`(모든 연구/논문/문서/방법 · 공통(된|으로|적|점) · 모두 … 공유/같/일치/보여) 에 걸리는 문장만 지운다. 묶음 규칙은 쓰지 않는다. 인용 문장이 안 남으면 그대로.
- 값 `1` 은 conclusion_drop2_1025 의 두 규칙 모두(기각, 운영에서 쓰지 않음).

## 2. 방법

- **새 질문 40** (`questions.tsv`, 측정 전 고정): 주제형 정리 E01–E30 · 비교 E31–E40. 이전 세트(pb1 · cd2 등)와 다른 주제 · 문장. 질문을 30 → 40 으로 늘린 이유: 이전 라운드에서 일반화 규칙이 걸린 답이 7/27 이라 유의(≥ 6)를 넘기려면 대상이 더 필요.
- 맥미니에서 운영 설정(`.env` 그대로, 플래그 0)으로 답 생성: `scripts/eval_e2e_ko.py --answer --save-context --questions …/questions.tsv --gold …/gold.jsonl --label cov_new`.
- 저장 답의 결론 다시 쓰기 대상(본론이 논문 2편 이상 인용)에 일반화 규칙을 오프라인 적용.
- **눈가림 판정:** 규칙이 걸린 답의 결론 전체 문장을 지울지 표시 없이 섞어 인용 블록과 함께 내보내고 문장마다 라벨(O · E · X · U · F · ?). 판정 뒤 규칙을 적용해 전 · 후를 센다.

## 3. 판정 (측정 전 고정)

| 지표 | 기준 |
|---|---|
| **주:** 답마다 결론의 (E + X) 문장 수 — 뒤 대 전 | 뒤가 적은 답 > 많은 답, 부호 검정 양측 p < 0.05 (적은 답 ≥ 6 필요) |
| 보호: 지운 문장 중 정확(O) 비율 | ≤ 1/3 |
| 보호: 결론의 근거 결과(수치 + 인용)를 잃은 답 | ≤ 1 |

| 보고: 대상 답 · 규칙 적용 답 · 지운 문장 수 · 지운 뒤 첫 문장이 접속어(반면 · 또한 · 따라서 · 이러한)인 답 | |

**결정: 기각** (주 기준 미달). 운영 변경 없음.

- 지운 O 2 개: "두 연구 모두 … 공통된 결론"(Q01, 두 논문이 실제로 같은 결과) · "LoRA 가 파라미터 효율적이라는 공통된 결과"(Q04) — `_OVERGEN` 은 옳은 "공통" 문장도 잡는다.
- 걸리는 빈도가 낮다(7 / 32 = 22%, conclusion_drop2_1025 는 7 / 27). 답마다 지우는 문장은 1 개뿐이라 결론 품질에 주는 영향 자체가 작다. 남은 오류는 대부분 규칙이 못 잡는 형태 — 논문 ID 를 엉뚱한 내용에 붙이기(Q03.2 · Q03.3 E), "이러한 결과들은 … 시사한다" 류 일반화(Q00.2).
- 보고만(사전 등록 아님): drop2 의 일반화 규칙 몫(7 / 7 X)과 합치면 지운 14 문장 중 X 12 · O 2.
