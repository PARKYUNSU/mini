# 질문 기간 · 편수 조건 규칙 (사전 등록, 2026-10-25)

> 측정 **전에** 쓴다. 출발점: qcond_1025 기준선 — 조건 문제 답 18%. 컨텍스트에 근거가 없을 때 밝히기는 잘 되고(15 중 13), 남은 문제는 **기간**(3 중 2: 블록 `[발행일]` 을 무시하고 2024 · 2025 논문을 "2026년 연구"로) · **편수**(5 중 2: "6편"에 5편, 9편 컨텍스트에 3편만 다루고 안 밝힘).

## 1. 바꾸는 것 — `RAG_COND_CHECK=1` (기본 0, LLM 호출 없음)

`core/llm/question_conditions.py`, 테스트 `tests/unit/test_question_conditions.py`.

- **기간 거르기:** 질문에서 `YYYY년` + (이후 · 부터 → 이상 / 이전 · 전 → 미만 / 까지 → 이하 / 없음 → 그해)를 뽑아, 답변 전에(관련 문서 거르기 뒤 · 번호 매기기 전) 블록을 `[발행일]` 연도로 거른다. 맞는 블록이 하나도 없으면 거르지 않고 그대로 둔다.
- **고지:** 답 맨 앞에 `※ …` 한 줄 — ① 기간에 맞는 블록이 없었으면 "요청한 기간(…)에 나온 논문은 찾지 못해, 기간 밖 논문으로 답했습니다." ② 질문의 `N개 · N편`(2–10)보다 본론 번호 항목이 적으면 "요청한 N편 중 M편만 찾았습니다."

## 2. 방법

- **새 질문 40** (`questions.tsv`, 측정 전 고정): 기간만 P01–P16 · 편수만 P17–P32 · 둘 다 P33–P40. qcond_1025 와 다른 문장.
- 맥미니에서 같은 질문을 두 조건으로 답 생성(운영 `.env`, 다른 설정 같음): `cr0`(플래그 0) · `cr1`(`RAG_COND_CHECK=1`). `--answer --save-context`.
- **눈가림 판정:** 질문마다 두 답을 무작위 A · B 로 섞어(시드 1025), 답과 그 답의 블록(발행일 포함)을 보고 조건마다 qcond_1025 라벨: `S` 충족 · `D` 못 채움을 밝힘 · `U` 못 채우고 안 밝힘 · `F` 거짓 충족(기간 밖 논문을 맞다고 · "N편"이라 하고 적게 등). **편수 조건의 S 는 요청 수를 다 냄**, 적게 냈어도 몇 편인지 밝히면 D. 판정 뒤 공개.
- RAG 답이 아닌 문항은 두 조건 모두 뺀다.

## 3. 판정 (측정 전 고정)

| 지표 | 기준 |
|---|---|
| **주:** 질문마다 (U + F) 조건 수 — cr1 대 cr0 | cr1 이 적은 질문 > 많은 질문, 부호 검정 양측 p < 0.05 |
| 보호: 충족(S) 조건 수 합 | cr1 ≥ cr0 − 3 |
| 보호: 기간 거르기 뒤 문서가 1 편 이하로 줄어든 질문 중 답이 "찾지 못함"이 된 질문 | 보고 |
| 보호: 응답 시간 중앙 | ≤ cr0 + 3s |
| 보고: 유형별(기간 · 편수) 라벨 · 거르기 상태 분포 · 고지가 붙은 답 수 · 잘못 붙은 고지(조건을 다 채웠는데 붙음) | |

채택이면 사용자 승인 후 운영 `.env` `RAG_COND_CHECK=1` + 봇 재시작.

**결정: 채택.** 사용자 승인 후 운영 `.env` `RAG_COND_CHECK=1` + 봇 재시작.

- **기간:** cr0 은 2024 · 2025 논문을 "2026년 연구"로 소개하는 거짓 충족이 11 번(P01 · P09 · P34 등). cr1 은 블록을 발행일로 걸러 이것이 2 로 줄었다.
- **cr1 에 남은 F 2 (P03 · P35):** 맞는 문서가 없어 거르지 않은 경우. 고지("요청한 기간에 나온 논문은 찾지 못해")는 붙었지만 본문이 여전히 "2024년 이전 연구가 존재한다"고 쓴다 — 고지와 본문이 어긋난다. 후속 후보: 맞는 문서가 없을 때 답 프롬프트에도 기간 밖임을 알리기.
- **편수:** cr0 은 적게 내고 안 밝힌 U 6. cr1 은 고지로 전부 D 가 됐다. 다만 P33 은 기간에 맞는 블록이 8 편인데 답이 3 편만 다뤄 "4편 중 3편만 찾았습니다"가 붙었다 — 사실은 "다뤘습니다"에 가깝다. 고지 문구는 답에 대해 맞지만 검색 결과에 대해서는 틀릴 수 있다.
- **한계:** cr1 답 맨 앞의 `※` 고지 줄 때문에 판정 때 조건이 드러난다(완전한 눈가림 아님). 편수 D 는 고지 자체로 정해지므로 편수 몫은 사실상 규칙 확인이다. 기간 S · F 는 각 항목의 발행일로 판정해 고지와 무관하다. 판정자 1 명(Claude).
