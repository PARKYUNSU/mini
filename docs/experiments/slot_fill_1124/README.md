## 3. 무엇 (`core/llm/slot_fill.py`, 플래그 `RAG_SLOT_FILL`, 기본 0)
칸 틀을 쓰고 집계가 (a)/(b) 일 때만.
1. `dedupe_repeated_heads` — 한 항목 안에서 인용 뒤에 항목 머리와 같은 굵은 이름이 다시 나오면 그 머리만 지운다(내용은 둠). 항목 다시 쓰기 앞.
2. `fill_missing_slots` — 칸 받은 직접 · 부분 논문(앞 5편) 중 본론에 인용이 없는 논문마다, 항목 다시 쓰기와 같은 프롬프트 · 검사(`check_item`: 길이 · 한자 · 문서 밖 숫자)로 그 논문 블록 하나만 보고 항목을 만들어 결론 앞에 붙인다. 이름은 논문 제목 앞부분, 부분이면 `(관련 연구)`. 검사 탈락이면 칸을 비워 둔다. 항목 다시 쓰기 뒤, 결론 다시 쓰기 앞.

## 4. 사전 등록 (측정 전, 11-24)
실행: 플래그 1 로 dev10 · K30 · L30 · N30 을 돌리고(trace `slot_fill`), **걸린 문항만** 플래그 0 으로 다시 돌려 짝을 만든다(seed 고정이라 안 걸린 문항은 플래그와 무관하게 같다 — 걸리지 않은 문항 중 3개를 플래그 0 으로도 돌려 글자까지 같은지 확인).
- 주 지표: 걸린 문항의 빠진 칸 합계가 줄어든다(채움 ≥ 빠짐의 절반).
- 보호 1: 채운 항목을 초록과 대조(Claude 판정)해 사실 오류 0.
- 보호 2: 걸린 문항 블라인드 쌍에서 플래그 1 이 나쁨 ≤ 1.
- 보호 3: 안 걸린 확인 문항 3개 답이 플래그 0 과 같다.
- 참고: 걸린 문항 수 · 문항당 시간 증가.
걸린 문항이 3 미만이면 부호 검정은 하지 않고 위 기계 지표 · 보호만으로 정한다.
