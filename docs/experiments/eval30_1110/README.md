## 3. 지표 ([`score.py`](score.py), 측정 전 고정)

- **Recall@15:** 정답 논문이 검색 단계 15편(`trace` search) 안에 있는가.
- **Recall@5:** 정답 논문이 거른 뒤 답에 들어가는 문서(`doc_ids`) 안에 있는가.
- 유형별 판정:
  - NM · NU: 정답 1편.
  - CP: 두 편 모두 · 하나 이상.
  - SV: 5편 중 정답 3편 이상.
  - MU(HU): 5편이 덮는 주제 수. 라벨이 없는 새 문서는 측정 뒤 Claude 가 같은 기준(`topic_split2_1104` §3)으로 달고 따로 센다.
  - MU(작업 141): E1 · E2 · E3 를 덮는가.
- **한/영 쌍:** 6쌍의 Recall@15 · @5 를 나란히 본다. 6쌍뿐이라 검정은 하지 않는다.
- **시간:** 단계별 중앙값.

판정 기준은 없다. 지금 파이프라인의 **기준선**이고, 뒤의 개선(수집 보강 · 새 맥미니 모델)을 같은 세트로 다시 재 비교한다. 답 단계 지표(요소 커버리지 · 인용 · 근거 · '모름')는 `--answer` 로 따로 잰다.
