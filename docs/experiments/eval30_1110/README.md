### 6.1 사전 등록과 다른 점

- **결론(D) 정의를 라벨 중에 좁혔다.** 사전 등록은 "결론에 본론이 뒷받침하지 않는 주장이 있으면 Y" 였다. 그런데 운영 결론 다시 쓰기(`RAG_CONCLUSION_REWRITE=1` · `RAG_CONCLUSION_PROMPT=v2`)는 본론이 아니라 초록의 결과 문장으로 결론을 쓴다. 이 정의로는 문서에 있는 새 사실도 Y 가 된다. 그래서 D 열은 **결론이 본론 · 문서와 모순되거나, 결과를 다른 논문 · 방법에 붙이거나, 근거 없이 넓게 단정할 때만** Y 로 달았다. 사전 등록 정의는 메모 칸에 `strictD` 로 함께 적었다.
- **첫 라벨 묶음이 인용 블록을 1600자에서 잘랐다.** 블록 109개 중 55개가 잘렸다(중앙 1607자 · 최대 2516자). 그래서 잘린 뒤쪽에 근거가 있는 주장을 근거 없다고 봤다. `packet()` 의 자르기를 빼고 묶음을 다시 만들었다. 잘리지 않은 블록으로 10개 답을 다시 봤다. 표본에서 근거 없음을 센 3개(HU27 · MU1 · MS2)와, 표본 밖에서 오귀속 · 결론을 판단한 7개(NM3 · NM4 · T07 · HU17 · HU39 · N11 · MU1E)다. 0개로 센 표본 7개는 블록이 길어져도 바뀌지 않는다.
- **다시 보고 바뀐 것:** 근거 없는 주장 8 → 5(HU27 3 → 2 · MS2 4 → 2). HU27 요소 3 은 △ → O 다(개선 분류기의 거부율 감소 · 오탐 1.74% 가 블록 뒤쪽에 있었다). T07 오귀속 의심은 철회한다. NM3 은 오귀속이 아니라 2차 인용 속 반대 주장이다. MS2 는 통째로 지어낸 것이 아니라 RAGSmith 관련 연구 단락의 HyDE 소개를 옮겼다.
