## 확장이 의도대로 작동했다

**옛 54문항이었다면 아무것도 안 보였다.** 잡담·계획에서 base 가 0% 였으므로 불일치가 생길 수 없었고, 실제로 v9·v10 라운드 모두 옛 문항 16개(잡담 8 + 계획 8)는 **양쪽 다 전부 통과**했다. 새로 넣은 16개에서만 차이가 나왔다.

새 문항이 재는 것은 **지시한 형식을 지키는 능력**이다 (정확히 N줄 · 줄당 N자 · JSON만). 기존 판정기는 붕괴 탐지기라 내용을 채점하지 않았고, 그래서 세 운영 슬롯이 천장에 닿아 있었다 ([`../yunsur_v10/05_conclusion.md`](../yunsur_v10/05_conclusion.md) §2).

## 관측 — v10 이 base 보다 나은 방향이다 (유의하지 않음) ⚠️ 절반만 재현됐다

v10 은 70문항에서 base 대비 **base만 실패 7 : v10만 실패 2** 로 한쪽에 쏠렸다 (p=0.180). 계획 슬롯만 보면 **4 : 0** (p=0.125) 이다. v9 은 같은 문항에서 4 : 5 로 갈려 p=1.000 이었다.

**유의하지 않다는 점을 먼저 적는다.** §2.3 기준으로 불일치 9쌍이 **한쪽으로 완전히 쏠려야** p<0.05 인데 지금은 7:2 다. 그리고 v10 vs v9 직접 비교는 **다른 밤의 측정**이라 판정에 쓸 수 없다 — 다만 base 가 두 밤에 거의 같았다는 사실은 그 비교의 방해 요인 하나를 줄여 준다.

그래도 기록해 둘 이유가 있다. **일곱 라운드 만에 처음으로, 학습한 모델이 운영 슬롯에서 base 보다 나은 쪽으로 쏠린 관측이다.** 지금까지는 "나빠지지 않았다" 가 최선이었다 ([`README.md`](../README.md) 의 궤적). 해석 후보는 lr 인하(2e-4 → 5e-5)가 형식 규율을 덜 망가뜨렸다는 것인데, **이 측정으로는 확인되지 않는다.**

확인하려면 **v9 과 v10 을 같은 세션에서 짝지어** 재야 한다. 지금은 각자 base 와만 짝지어져 있다.

> **[2026-09-29 오전 추가] 그렇게 재봤고, 이 절의 관측은 절반만 재현됐다.** 같은 비교가 7:2 → **6:4**(p=0.754) 로 약해졌다 — 쏠림의 상당 부분은 노이즈였다. 재현된 것은 **계획 슬롯 하나**뿐이다. 아래 [3모델 라운드](#3모델-라운드--같은-세션에서-basev9v10-2026-09-29-0841--1125-164분) 참고.

## 계획 문항에 대한 판단을 철회했다

2026-09-28 에 계획 제약 문항 8개를 "양쪽 다 실패해 변별력이 없다" 고 보고 상한 완화를 §5 에 적었다. **철회했다** ([`../protocol.md`](../protocol.md) §6). v10 이 그중 4개(`planner_10`·`12`·`15`·`16`)를 통과한다 — 문항이 무력한 것이 아니라 v9 이 그 구간을 못 넘었던 것이다. 완화했다면 재려던 신호를 지웠을 것이다.

한 모델의 결과만으로 문항 결함을 단정한 실수였고, 같은 실수를 전날 파일럿에서도 했다 (base 하나로만 재고 "양쪽 다 실패" 와 "변별력 있음" 을 구분하지 못했다).

### 어제의 관측은 절반만 재현됐다

전날 v10 라운드에서 base 대비 **7:2** (p=0.180) 로 쏠린 것을 두고 "일곱 라운드 만에 처음으로 학습 모델이 base 보다 나은 방향" 이라고 적었다. 오늘 같은 비교는 **6:4** (p=0.754) 다. **그 쏠림의 상당 부분은 노이즈였다.**

재현된 것은 **계획 슬롯 하나**다.

| | base만 실패 : v10만 실패 | 계획 실패율 |
|---|---|---|
| 09-29 새벽 (base:v10) | **4 : 0** | 47.9% → 27.1% |
| 09-29 오전 (base:v10) | **3 : 0** | 50.0% → 31.2% |
| 09-29 오전 (v9:v10) | **3 : 0** | 47.9% → 31.2% |

v10 은 계획 제약 문항 3~4개(`planner_10`·`12`·`16`, 전날은 `15` 포함)를 통과하고 base·v9 은 실패한다. **세 비교에서 한 번도 방향이 뒤집히지 않았다.**

**그래도 유의하지 않고, 합쳐서도 안 된다.** 각 비교의 p 는 0.125~0.250 이다. 두 밤의 결과를 합치고 싶어지지만 **같은 문항을 두 번 잰 것**이라 독립 표본이 아니다 — 불일치를 만든 문항이 양쪽 밤에 거의 동일하다(`planner_10`·`12`·`16`). 합쳐서 p 를 계산하면 같은 증거를 두 번 세는 것이 된다.

정직한 요약은 이렇다: **v10 은 계획 제약 문항 3~4개에서 재현 가능하게 낫다. 그 밖에는 base·v9 과 구분되지 않는다.**
