# pdf_decimal_1107: PDF 깨진 소수점 고치기 (사전 등록, 2026-11-07, dev)

> 측정 **전에** 쓴다. 출발점: [`unit_check_1106`](../unit_check_1106/README.md) §7 에서 본 뒤 찾은 문제다. 사용자 결정(11-06): 작은 라운드로 등록한다.

## 0. 진단

PDF 본문 추출(`pymupdf4llm`)이 소수점을 `87 _._ 5%` · `2 _._ 35` · `0_._594` 꼴로 남긴다.

- 코퍼스 7,928편 중 4,453편(56.2%), 합 272,106곳이다. 초록(arXiv 메타데이터)에는 0 이다.
- 답 2개에서 숫자가 틀렸다: C09 '2 × 35배'(원문 2.35배), HU39 '87%'(원문 87.5%).
- `body_numbers` 는 못 잡는다. 조각 숫자 `35` 가 블록에 그대로 있기 때문이다.
- 저장 dev 답 약 620문항 중 컨텍스트에 든 문항은 14 로 **노출은 약 2% 다.** 답 컨텍스트 대부분이 초록이기 때문이다. 큰 효과는 기대하지 않는다.

## 1. 바꾸는 것 — `RAG_FIX_PDF_DECIMAL` (기본 `0`)

`1` 이면 `core/rag/agent_chroma_rag.py` `_format_chroma_hits` 가 청크 본문을 1,200자로 자르기 **전에** 다음을 바꾼다.

```
(?<=\d) *_\._ *(?=\d)  →  .
```

- 재색인이 없다. BM25 · 임베딩 · 재순위는 원문 그대로라 검색 순위는 바뀌지 않는다. 글자가 줄어 1,200자 안에 조금 더 들어갈 수는 있다.
- 대상은 `_._` 하나다. 답 오류의 증거가 있는 꼴만 고친다. 다음은 뺀다.
  - `_,_`: 뒤 자릿수가 1–2 인 곳이 80% 로 대부분 목록 · 좌표이고, 천 단위로 잘못 묶으면 `body_numbers` 가 맞는 문장을 지울 수 있다.
  - `_×`: 고치지 않아도 읽힌다.
  - `0 . 16`(84/1,464편, 주로 그림 글자) · `**2** . **17**`(1/1,464편).
- **규칙 점검(측정 전, 오프라인):** 바뀌는 자리 100곳(seed 11071)을 읽었다. 소수 · 버전(`Yi-1.5`) · 절 번호(`RQ 1.2`)뿐이고 잘못 바뀌는 곳은 0 이다.

## 2. 방법

- **문항:** 10-26 11:00 뒤 저장 결과에서 컨텍스트에 깨진 소수점이 한 번이라도 든 dev 문항 14개다([`questions.tsv`](questions.tsv) · [`gold.jsonl`](gold.jsonl)). 원래 세트에 정답이 없는 문항은 검색 ok 에서 빠진다.
- **측정:** [`run.sh`](run.sh)가 같은 문항을 대조 `pd0` → 처리 `pd1` 순서로 `--answer --save-context` 로 돌린다. 운영 `.env` 는 바꾸지 않고 평가 프로세스 환경변수로만 켠다. 약 40–50분이다.
- **시간:** 01:00 수집(Chroma 쓰기)과 일요일 04:00 주간 점검을 피한다.
- **held-out 은 쓰지 않는다.** 노출이 약 2% 라 90문항 중 2–3문항만 바뀐다. §2.5 부호 검정은 4:1 효과에도 동점 뺀 12문항이 필요해 넘을 수 없다. 그래서 `abstract_tail_1021` 처럼 버그 수정으로 보고 기계 기준과 손해 없음으로 판정한다. 깨진 소수점이 없는 문항에서는 함수가 글자를 바꾸지 않는다(단위 시험).

## 3. 판정 (측정 전 고정, [`score.py`](score.py))

| 지표 | 기준 |
|---|---|
| **주(기계):** 처리 컨텍스트의 깨진 소수점 | 0곳 |
| **주(효과):** 조각 오류 문항(라벨 T) | 처리 < 대조, 처리만 오류인 문항 0 |
| 보호: 오류 | 0 |
| 보호: 검색 ok | 처리가 대조보다 2 이상 낮지 않음 |
| 보호: 컨텍스트 밖 인용 합 | 대조 + 1 이내 |
| 보호: 판정 '없음' 문항 | 대조 ± 2 이내 |
| 보호: 응답 시간 중앙 | 대조 + 5s 이내 |
| 보고: 답 입력 같은 문항 · `doc_ids` 같은 문항 · 소수를 맞게 쓴 자리 | |

- **조각 오류 후보:** 대조 컨텍스트의 깨진 소수 `a.b` 를 답이 그대로 쓰지 않고, `a × b` 처럼 쪼개거나 `a` · `b` 만 원문과 같은 단위로 쓴 자리다. 후보를 대조 · 처리 섞어 눈가림 묶음으로 만들고 Claude 가 원문과 대조해 T · F · ? 를 단다.
- **대조 T 가 0 이면** 효과는 '재현 안 됨'으로 적고, 기계 · 보호만 통과했을 때 버그 수정으로 사용자에게 올린다.
- **통과:** 사용자 승인 후 운영 `.env` `RAG_FIX_PDF_DECIMAL=1` · [`ops/settings.md`](../../../ops/settings.md) 줄 추가 · 봇 재시작.
- **미달:** 플래그 코드를 지운다.
