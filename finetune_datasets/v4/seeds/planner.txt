# planner 시드 — "도구 만들어줘 / ~해줘" 류 작업 요청. 한 줄에 한 문장.
# 평가 문항과 비슷한 문장은 자동 제외됨.
# ---- 웹·크롤링 ----
네이버 뉴스 IT 섹션 헤드라인 10개 긁어오는 도구 만들어줘
유튜브 채널 최신 영상 제목 5개 가져오는 도구 만들어줘
깃허브에서 langchain 레포 스타 수 확인하는 도구 만들어줘
교보문고 베스트셀러 1위부터 5위까지 알려주는 도구
오늘 코스피 종가 알려주는 도구 하나 만들어줘
위키백과에서 특정 단어 첫 문단만 가져오는 도구 만들어줘
# ---- 파일·데이터 처리 ----
다운로드 폴더에 있는 pdf 파일 이름을 날짜순으로 정리해줘
엑셀 파일에서 이메일 컬럼만 뽑아서 중복 제거하고 txt로 저장해줘
csv 두 개를 이메일 기준으로 합쳐서 중복 제거해줘
폴더 안 이미지들을 전부 800px 폭으로 리사이즈하는 도구
json 로그 파일에서 error 레벨만 골라서 개수 세줘
텍스트 파일에서 가장 많이 나온 단어 20개 뽑아줘
여러 마크다운 파일의 제목만 모아서 목차 만들어줘
# ---- API·외부 서비스 ----
공공데이터포털에서 오늘 미세먼지 등급 가져오는 도구 만들어줘
오픈웨더로 부산 내일 날씨 알려주는 도구
환율 API로 달러 원 환율 가져와서 알려줘
구글 시트 특정 탭 내용을 읽어서 요약해주는 도구
텔레그램으로 매시간 서버 상태 보내는 도구 만들어줘
# ---- 스케줄·자동화 ----
매일 아침 8시에 오늘 일정 요약해서 보내는 스케줄 등록해줘
평일 저녁 7시에 스마트플러그 꺼주는 스케줄 잡아줘
매주 월요일 9시에 지난주 arXiv 논문 큐 개수 알려줘
30분마다 특정 웹페이지 바뀌었는지 체크하는 도구
# ---- 분석·계산 ----
지난달 카드 내역 csv 읽어서 카테고리별 지출 합계 내줘
매출 데이터에서 월별 추이 그래프 png로 그려줘
설문 결과 csv에서 5점 척도 평균이랑 표준편차 계산해줘
두 텍스트 파일의 차이점만 보여주는 도구
로또 최근 10회차 번호 빈도 분석해줘
# ---- 기타 ----
내 논문 DB에서 transformer 관련 논문 제목만 목록으로 뽑아줘
아까 만든 날씨 도구랑 환율 도구 합쳐서 아침 브리핑 하나로 만들어줘
영어 단어 리스트 주면 뜻이랑 예문 붙여서 표로 만들어주는 도구
